# 页岩油 CO₂ 吞吐场重构精度分析

> 针对 `shale_oil`（GEM 组分模型导出，15×15×15，30 cm 立方）的场重构结果与改进记录。

## 一、数据特征

| 项 | 值 |
|---|---|
| 模型 | GEM Peng–Robinson，14 组分，120 ℃，20 MPa |
| 几何 | 15×15×15，格子 0.02 m，k=0 底 / k=14 顶 |
| 孔隙度 | 0.05（常值） |
| 渗透率 | 0.03 mD（常值，近均质） |
| 注入 | INJ 井注纯 CO₂，8.333e-8 m³/s（储层条件） |
| 生产 | PROD1–4 采油，井底压力下限 19 MPa |
| 测点 | 16 个，位于 k=4 与 k=10 两层、i/j ∈ {4,7,10} 的环带（中心 (7,7) 无测点，是注入井所在） |

关键物理：**CO₂ 在 20 MPa 下超临界、高度溶于油**（组分行为）。注入的 CO₂ 大部分溶解进油相（使油溶胀），仅少量以自由气相存在，且自由气相**重力分异到模型底部**（k=0–2）后随时间逐渐溶解消失（630 天后全场 sg=0）。

## 二、重构结果（改进后）

| 场 | 相对误差 | 说明 |
|---|---|---|
| k（渗透率） | **3.1%** | P1 平滑权重 0.15→2.0 + P2 relperm 联合反演，从 34.3% 降下来 |
| p（压力） | **0.1%** | 平滑全局场，插值足够 |
| phi（孔隙度） | **0.0%** | 常值场，精确 |
| sw | 0 | 无注水，恒 0 |
| so / sg | **4.3%** | 见下：测点盲区 |

累计：k 相对误差 **34.3% → 3.1%（−91%）**。

## 三、so/sg 4.3% 误差的根因（测点盲区，非算法）

逐时间步 RMSE 显示：so/sg 误差**全部集中在头 ~10 步（30–330 天）**，之后精确为 0。

诊断结论（见 `comparison/plume_vs_probes.png`）：

1. **16 个测点在全部 120 步上 sg 观测恒为 0、so 恒为 1**——测点从未"看到"羽流。
2. 真值羽流集中在**底层**：k=0–2 层 `mean(sg)=0.456`、49% 格子 sg>0.1；而测点所在的 k=4/10 层 `mean(sg)=0.072`、仅 7.8% 格子 sg>0.1。
3. 压力/渗透率/孔隙度是**平滑全局场**，16 个测点足够；饱和度是**局部突变场**（底部自由气羽流），16 个错位测点结构性地漏掉了它。

因此：**任何插值/克里金算法都无法从"全 0"观测重构出羽流**——信息本身不存在。这是测点布设问题（数据盲区），不是重构算法问题。进一步叠加黑油前向模型或注入量约束（P3/P4）反而会更差：黑油模型把 CO₂ 当永久气相，而真值中自由气溶解消失（630 天后 sg=0）；累计注入量 ≈ 25.9 m³ 与自由气体积 ≈ 1e-4 m³ 相差 5 个数量级（CO₂ 溶解进油），"注入=自由气"的守恒不成立。

## 四、改进建议

1. **测点布设（最高杠杆）**：把测点放到**底层 k=0–2**（羽流所在），而非 k=4/10 的中部环带；建议底部 3 层每层 3×3 或 4×4 网格。这将直接消除 so/sg 的 4.3% 误差。
2. **组分一致性**：若饱和度精度对项目关键，场重构需升级为**组分模型**（追踪 CO₂ 组分质量：自由气 + 溶解气），黑油三相模型无法刻画 CO₂ 溶解/溶胀/密度反转的相行为。这是较大的架构升级，需单独立项。
3. **k/p/phi 已达标**：3.1% / 0.1% / 0.0%，无需继续投入。

## 六、CO₂ 组分追踪升级 + 测点迁移（后续迭代）

### 6.1 CO₂ 组分追踪（黑油三相 → 自由气 + 溶解气）

- `BlackOilParams` 增 `rs_slope`（亨利定律 `Rs = rs_slope·p`）、`bo_slope`（溶胀，预留）；新增 `solution_gas_ratio(p, params)`。
- `pipeline.py` 输出 `rs`（溶解气比 `=rs_slope·p`）与 `co2`（总 CO₂ 组分 `=sg+Rs·so`）。
- `case.yaml` 配 `rs_slope: 9.84e-6` → **Rs ≈ 187.5 m³/m³，与数据估算 187 精确吻合**（此前黑油模型完全漏掉这 99.9% 的溶解气）。
- **反演保持分相平衡**：曾把气相残差改成 CO₂ 组分残差，但本案例油相主导、Rs 巨大，组分残差 ≈ `Rs×油相残差`（冗余），且把 q_scale 放大 30 倍，k 退化到 12.77%。故 k 反演（流量）与 CO₂ 追踪（组分）分离。

### 6.2 测点迁移到底层 k=0/1/2（27 个，与井位对齐）

测点从 k=4/10 迁到底层，10/27 测点现在观测到 sg>0（最高 0.98），盲区已修复。但：

| 场 | 迁移前（16 测点） | 迁移后（27 测点） | 说明 |
|---|---|---|---|
| p | 0.1% | 0.2% | 仍准 |
| so / sg | 4.3%（漏报） | **4.3%（过报）** | 克里金把底层羽流抹到全模型；测点对羽流过采样（均值 0.34 vs 真值 0.15） |
| k | 3.1% | **均值 0.00%、空间变异 16–19%** | 羽流进入饱和度输入后，k 反演用空间变化 k 拟合局部气流（真值 k 常数） |

**根因**：羽流是**局部、瞬态、细尺度**特征（重力分异 + 气油过渡带），普通克里金 + 平稳反演无法刻画。测点迁移是必要但非充分——真正的修复是**前向模型（P3）**：用带溶解气的扩展黑油模型前向模拟羽流（质量守恒），而非克里金插值。Rs 扩展已是前向模型的基础。

### 7.2 底部羽流输运路径（用 observations.csv 真值数据查清）

day30 底部 27 测点：**10 个 sg>0.05，且 sg ≈ 0.80–0.98（高饱和、近纯气）**，其余 17 个 sg=0。day30 底部压力 19.0023–19.0658 MPa，注入井 k=8 峰值 19.103、k=0 生产 19.034（69 kPa 井压差）。

**结论：底部羽流是「注入的过量自由气以气相 Darcy 下流到底部累积」，不是「溶解 CO₂ 随油下流再析出」**——后者贡献很小（Rs_sat 139→113 压降 0.2 MPa 只析出 ~5%）。此前文档「溶解-析出是主机理」的判断需更正。

| 环节 | 真值 | 模型 |
|---|---|---|
| 注入井自由气 sg | ~0.71 | ~0.071 |
| 气体流度 λg | 高（krg≈0.9） | 低（krg≈0.006→λg≈322） |
| 自由气下流到底 | ~30 天 | ~72 天（慢 2.4×） |
| 底部累积 | sg 0.8–0.98 | 无（堆顶部） |

### 7.3 欠产 ~1000× 的三层根因

1. **C 裁剪丢质量**：线搜索 `C_new` 上界 `1/Bg·(1-sw)` 把超量 CO₂ 直接丢。放开后自由气 120→466 格、单格 `C.sum()==注入量` 精确守恒。
2. **气体流度太低**：SGT 表 `sg≤0.05→krg=0`（残余气），模型 sg~0.07→λg≈306 vs 真值 sg~0.71→λg≈45000（差 160×），排不掉多余 CO₂。
3. **压降/注速偏**：压降 0.020 vs 真值 0.222 MPa（65× 偏小）、注速偏快 6×。根因是「真值注入井 sg≈0.71 → 油相相对渗透率暴跌到 kro=0.0153、有效流度 7.65」vs 模型用初始 λo=500。**不是可压缩拟压力（修正仅 0.6%）也不是 geofac（0.34 只差 1.7×）**。

### 7.4 闭环根因与结论

三条根因构成**「饱和 ↔ 流度 ↔ 注速」闭环**：C 守恒 → 注入井累积自由气到 sg≈0.71 → 气体流度高 → 下流到底部羽流 → 油相流度暴跌 → 压降/注速自纠。OPM/MRST 的 fully-implicit（压力+饱和度+井耦合）正是这样自然算出这条链；本项目的解耦做法（压力解用当前流度 + 固定井速率）解不了这个闭环。

**后续方向**：若要自由气沉底，需 fully-implicit 耦合（压力+饱和度+井同时解），属架构级立项，非单点 bug 修复。当前 so/sg 最优仍是克里金 ~4.3%（集中在 day30 羽流过采样）；p/phi/k/sw 已达标（0–0.2%）。
