# 在线对接（online 案例快速上手）

三个角色、三个端口。测点和注采走 TCP，反演结果走两路 UDP。字节序一律小端，协议版本 2。
**完整协议见 [`docs/接口协议.md`](../../docs/接口协议.md)，联调步骤见
[`docs/联调指南.md`](../../docs/联调指南.md)。**

```
采集端 send_steps.py  --TCP:9000-->  python -m src
仪表盘（对接方实现）  <--UDP:9001--  实验尺度
仪表盘（对接方实现）  <--UDP:9002--  矿场尺度
```

| 参数 | 协议 | 方向 | 默认示例 |
|---|---|---|---|
| `--tcp-port` | TCP | 采集端 → 本进程 | 9000 |
| `--lab-port` | UDP | 本进程 → 仪表盘 | 9001 |
| `--field-port` | UDP | 本进程 → 仪表盘 | 9002 |
| `--ip` | UDP 目的地址 | 结果发往哪里 | 127.0.0.1 |
| `--control-port` | UDP | 仪表盘 → 本进程（RESEND） | 无（可选） |

`--tcp-port` 没有默认值。本进程在 `0.0.0.0` 上听 TCP，`--ip` 只用于 UDP 出站。

## 启动顺序

先起反演，再发 TCP。

```bash
# 终端 1：反演（60×60×60，单步较慢；先跑 small 更快）
python -m src examples/online/case.yaml --tcp-port 9000 --ip 127.0.0.1 --lab-port 9001 --field-port 9002

# 终端 2：测点与注采
python examples/online/send_steps.py --host 127.0.0.1 --port 9000
```

仪表盘（对接方实现）在 9001 / 9002 收 UDP 场。

`case.yaml` 网格 60×60×60。测点、井位和 12 个月时序来自 `examples/shailoil.dat` 的
GEM 第一年结果（16 个测点、INJ + PROD1–4）。测点顺序 = `probes.csv` 行序（下标
0=P_5_5_5 … 15=P_11_11_11），井顺序 = `wells.csv` 行序（0=INJ，1–4=PROD1–4）。

## TCP 流程（协议 v2）

采集端 `connect` 一次，这条连接一直用到断开，不要每拍重连。双方开 `TCP_NODELAY`。

1. 后端 `accept` 后发 **HELLO**（JSON manifest：网格、测点/井下标顺序、枚举、单位）。
2. 采集端发 **READY** `{"version":2,"ok":true}`。
3. 采集端逐拍发 **STEP**（`[u32 seq][f64 time_s][u16 n_probe][u16 n_well][records]`，
   每条记录 `[u16 index][u8 code][f64 value]`），后端回 **ACK** / **NAK**（含错误码）。
4. 发完发 **BYE** 关闭。

`code`（测点 `quantity`）：1 压力 Pa、2 Sw、3 So、4 Sg。`kind`（注采）：1 井底压力 Pa、
2 注入 CO₂ m³/s、3 产水、4 产油、5 产气（流量填正数，种类决定注/采）。

组包可用 `src.programs.protocol.pack_step` + `frame_tcp`（参考 `send_steps.py`）。

## UDP 出站（协议 v2）

报头 `[2s"RB"][u8 ver][u8 type][u32 stream_id][u32 seq]`，消息 MANIFEST / FIELD /
RESULTS / END。FIELD 带 CRC32，END 带总报数+整体 CRC；接收端检测到丢包/损坏会报
`incomplete`（不会静默出数）。`field_id`：0=p 1=sw 2=so 3=sg 4=phi 5=k。

- `--lab-port` 是实验尺度（0.30 m 立方）。
- `--field-port` 是矿场尺度（本例 300 m × 300 m × 30 m），**只缩放几何与时间**，场值不变。
- 每收一拍后端把**累计后的整段**再发一遍；`RESULTS` 含井底压力 / 测点拟合误差等结果。
- 收流用 `src.programs.udp.receive_fields`（返回 manifest / fields / results）。
