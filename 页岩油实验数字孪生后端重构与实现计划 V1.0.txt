# 页岩油实验数字孪生后端重构与实现计划 V1.0

## 0. 总体目标

在现有油藏数值计算后端基础上，构建一套面向页岩油物理实验的数字孪生计算内核。

核心目标不是“同时反演所有储层参数”，而是：

> 以组分双重介质模型作为物理正演模型，以实际注采工况作为硬物理约束，以内部压力、饱和度等测点数据作为观测，通过 ES-MDA 和在线 Ensemble Parameter Filter 持续识别和校正裂缝等效导流能力，并由物理模型重新计算三维压力场、饱和度场和组分场。

第一阶段重点解决：

$$
\boxed{
\text{Compositional Dual-Continuum}
+
\text{Fracture Conductivity Inversion}
+
\text{Sensor Assimilation}
}
$$

不要在第一版扩展到复杂 SRV、显式裂缝网络、全空间渗透率场反演或 PINN。

---

# 1. 核心设计原则

整个系统必须坚持以下原则。

## 1.1 物理模型是真值生成器

压力场、饱和度场、组分场必须由守恒方程和物理模型求解产生。

禁止通过插值、神经网络或者 EnKF 直接修改出一个“不满足控制方程”的压力场作为最终结果。

结构必须是：

```text
参数
  ↓
物理正演
  ↓
状态场
  ↓
测点预测
  ↓
与实验观测比较
  ↓
更新参数
  ↓
重新物理正演
```

而不是：

```text
测点
 ↓
直接重建一个场
```

---

## 1.2 注采控制与观测必须区分

实验控制量：

* 注入流量；
* 注入压力；
* 生产井恒压；
* 生产井恒流；
* 温度；
* 边界封闭条件；

属于：

```text
BoundaryCondition / SourceTerm
```

必须进入正演模型。

例如：

$$
Q_{inj}(t)
$$

如果实验为恒流注入，则必须作为 Neumann/source constraint。

$$
P_{prod}(t)
$$

如果实验为恒压采出，则必须作为 Dirichlet boundary。

这些量不能被反演算法修改。

但非控制响应可以同时作为额外观测。

例如：

```text
恒流注入 Qinj      → hard constraint
生产压力 Pprod     → observation

恒压生产 Pprod     → hard constraint
生产流量 Qprod     → observation
```

---

# 2. V1 参数分类

必须建立明确的参数分类体系。

## 2.1 固定参数

V1 不反演：

```text
matrix permeability km
matrix porosity φm
matrix compressibility
fluid component properties
EOS parameters
PVT parameters
relative permeability parameters
capillary pressure parameters
rock density
temperature model parameters
matrix-fracture transfer coefficient / shape factor
```

这些参数：

> 可以参与每一个正演时间步，但不能因为“参与计算”就自动成为待反演参数。

---

## 2.2 主要反演量

V1 只反演：

$$
\boxed{C_f}
$$

定义为：

**effective fracture conductivity / effective fracture transmissibility**

它代表整个裂缝连续介质在当前模型尺度下的等效导流能力。

不要在 API 或报告中宣称：

```text
Cf = 某条真实裂缝的真实渗透率
```

双重介质模型得到的是等效参数。

内部可以定义：

$$
C_f \leftrightarrow k_f^{eff}
$$

或者直接映射到 fracture transmissibility。

推荐统一通过 `FractureConductivityModel` 封装。

---

# 3. Cf 参数化设计

必须从最简单形式开始。

## Level 1：Scalar Cf

V1：

$$
C_f = const.
$$

整个裂缝连续介质只有一个导流能力参数。

这是第一个必须跑通的版本。

---

## Level 2：Zonal Cf

V1.5：

$$
C_f =
[C_{f,1},C_{f,2},...,C_{f,N}]
$$

按照：

* 人工裂缝区；
* 高裂缝密度区；
* 构造区；
* 注入端附近；
* 生产端附近；

进行分区。

N 初期控制在：

```text
2 ~ 10
```

不要直接进入 cell-wise inversion。

---

## Level 3：Field Cf

以后才支持：

$$
C_f=C_f(x,y,z)
$$

禁止直接使用：

```text
125000 grid cells
=
125000 inversion parameters
```

必须使用低维参数化，例如：

```text
KLE
PCA
geological basis
zonal basis
fracture-zone basis
```

形式：

$$
\log C_f(x)
=
\bar m(x)
+
\sum_{i=1}^{r}a_i\phi_i(x)
$$

实际反演：

$$
a_1,...,a_r
$$

而不是所有网格值。

---

# 4. Cf 必须在 log-space 中反演

由于：

$$
C_f>0
$$

禁止直接在线性空间更新 Cf。

定义：

$$
m=\log C_f
$$

反演器更新：

$$
m
$$

之后：

$$
C_f=\exp(m)
$$

这样避免 EnKF / ES-MDA 更新出负渗透率或负导流能力。

实现统一接口：

```python
class Parameterization:
    def encode(self, physical_parameter):
        ...

    def decode(self, latent_parameter):
        ...
```

实现：

```python
LogConductivityParameterization
```

禁止把所有变量塞进无结构 ndarray。

建立明确的状态对象。

建议：

```python
@dataclass

@dataclass
class DualContinuumState:
    matrix: ContinuumState
    fracture: ContinuumState
    time: float
```

对于 N 个组分：

```text

    Pm

    Sm_alpha

```

```text

```

# 7. Fluid / EOS 层

必须将流体热力学与流动求解解耦。

接口：

```python
class FluidModel:
    def evaluate(self, pressure, temperature, composition):
        ...
```

返回至少：

```text
phase state
phase fraction
density
viscosity
phase composition
```

以后可以替换不同 EOS。

V1 可以先支持一个明确的 EOS 实现，但 API 不允许把某一种 EOS 写死进 FlowSolver。

结构：

```text
FlowSolver
    ↓
FluidModel interface
    ↓
EOS implementation
```

不要：

```text
FlowSolver
    ↓
直接写 PR EOS 具体公式
```

# 8. 双重介质传递项

基质和裂缝之间必须通过明确的 transfer operator 耦合：

$$
q_{mf}
=
\mathcal T_{mf}
(P_m,P_f,S_m,S_f,z_m,z_f)
$$

V1：

```text
matrix-fracture shape factor
transfer coefficient
matrix permeability
```

全部固定。

不要同时反演：

```text
Cf
+
shape factor
+
km
```

否则容易出现不可辨识性。

设计接口：

```python
class MatrixFractureTransferModel:
    def compute_transfer(...):
        ...
```

这样以后可以替换：

```text
Warren-Root
Kazemi
MINC-like
custom transfer
```

但 V1 只实现一个经过验证的模型。

# 12. 饱和度测点

电阻率、电磁、声波传感器应与储层反演分成两个层级。

第一层：

```text
raw signal
↓
sensor inversion
↓
saturation observation
```

第二层：

```text
saturation observation
↓
reservoir assimilation
```

定义：

```python
class SignalInversionModel:
    def invert(self, raw_signal):
        ...
```

例如以后实现：

```text
ResistivitySaturationModel
EMInversionModel
AcousticSaturationModel
```

最终统一输出：

```python
SaturationObservation(
    location,
    time,
    saturation,
    uncertainty,
)
```

储层 assimilation 不允许关心这个饱和度到底来自声波还是电阻率。

# 14. Observation uncertainty

所有测点必须支持：

$$
\sigma_{obs}
$$

Assimilation 使用：

$$
R
$$

作为 measurement covariance。

禁止默认认为：

```text
所有传感器完全准确
```

V1 可以先使用 block diagonal：

$$
R=
diag(\sigma_1^2,...,\sigma_n^2)
$$

未来再考虑 correlated errors。

# 15. History Matching 主算法：ES-MDA

V1 离线反演核心算法：

$$
\boxed{ES-MDA}
$$

用途：

> 使用一个实验时间窗口内的压力和饱和度测点数据，对裂缝导流能力进行后验估计。

---

# 16. ES-MDA 输入输出

输入：

```text
prior Cf distribution
ensemble size
observations
measurement covariance
forward model
number of assimilation steps
random seed
```

输出：

```text
posterior ensemble
posterior mean
posterior median
posterior std
quantiles
simulation responses
misfit history
```

---

# 17. Ensemble

例如：

$$
m_j^0=\log C_{f,j}
$$

生成：

$$
j=1,...,N_e
$$

每个 ensemble member：

```text
parameter
↓
full physical simulation
↓
predicted observations
```

即：

$$
y_j=F(m_j)
$$

---

# 18. ES-MDA 更新

实现基本更新：

$$
m_j^{a}
=
m_j^{f}
+
C_{my}
(C_{yy}+\alpha R)^{-1}
(d_j-y_j)
$$

多次 assimilation 满足：

$$
\sum_{k=1}^{N_a}\frac{1}{\alpha_k}=1
$$

V1 可以默认：

$$
\alpha_k=N_a
$$

但 API 必须允许用户配置。

---

# 19. ES-MDA 数值要求

必须处理：

```text
singular covariance
ill-conditioning
failed ensemble member
NaN simulation
outlier observation
```

矩阵求解禁止直接使用：

```python
np.linalg.inv(...)
```

优先：

```text
solve
Cholesky
SVD
regularized solve
```

根据数值情况选择。

---

# 20. Forward simulation failure

如果某个 ensemble 导致：

```text
non-convergence
negative phase state
EOS failure
NaN
```

不得整个 history matching 直接崩溃。

必须：

```text
记录失败 member
给出明确 reason
允许 retry
允许 rejection/resampling
```

V1 至少支持：

```text
failed-member replacement from valid prior neighborhood
```

所有行为必须进入报告。

---

# 21. Online Assimilation

在线实验阶段不能每秒完整运行 ES-MDA。

采用：

$$
\boxed{
Fast Forward Prediction
+
Slow Parameter Assimilation
}
$$

双时间尺度。

---

# 22. Fast loop

例如实验数据每秒到达：

```text
t
↓
读取 controls
↓
ForwardModel.step()
↓
计算 P/S/composition
↓
输出数字孪生状态
```

这一层可以是 1 s 数据周期。

但数值求解 dt 可以自行 substep，不要求：

```text
solver dt = 1 s
```

---

# 23. Slow assimilation loop

Cf 只在以下情况更新：

```text
每 N 秒
或
每一个实验阶段
或
innovation 超过阈值
或
人为触发
```

定义：

```python
AssimilationTrigger
```

实现：

```text
FixedIntervalTrigger
InnovationTrigger
ManualTrigger
```

---

# 24. Online algorithm

实现：

$$
\boxed{Parameter Ensemble Kalman Filter}
$$

而不是第一版就直接修改完整状态。

更新：

$$
m=\log C_f
$$

利用：

$$
C_{my}
$$

和：

$$
C_{yy}
$$

根据实时测点 innovation：

$$
d-y
$$

更新 ensemble。

---

# 25. 禁止直接覆盖压力场

V1 Online Assimilation：

禁止：

```text
P_sim → P_assimilated
S_sim → S_assimilated
```

然后直接把 `P_assimilated` 当物理解。

测点只能更新：

$$
C_f
$$

更新 Cf 后：

> 重新调用 ForwardModel 得到新的物理状态。

---

# 26. Online 参数更新后的物理一致性

由于更新：

$$
C_f^{old}\rightarrow C_f^{new}
$$

当前状态可能不再与新的 Cf 完全一致。

因此实现：

```text
assimilation checkpoint
```

每次参数更新后：

```text
恢复上一个 assimilation checkpoint
↓
使用 posterior Cf
↓
重新推进到当前时刻
```

即 fixed-lag rerun。

不要只修改当前时刻 Cf 然后继续往前跑。

V1 的 rollback window 可以等于：

```text
上一次 assimilation → 当前 assimilation
```

---

# 27. Online Cf dynamics

V1：

$$
C_f(t+1)=C_f(t)+\eta
$$

其中：

$$
\eta\sim N(0,Q_m)
$$

作为 parameter random walk。

`Q_m` 默认很小。

它表达：

> 裂缝导流能力可能缓慢演化。

不能设置过大，否则模型会追踪传感器噪声。

# 38. Synthetic Truth Test

这是 V1 最重要的验证。

首先人工指定：

$$
C_f^{true}
$$

使用 forward solver 生成 synthetic observations：

```text
pressure sensors
saturation sensors
production response
```

加入可控噪声：

$$
d_{obs}=d_{true}+\epsilon
$$

然后人为给一个错误 prior：

$$
C_f^{prior}\neq C_f^{true}
$$

运行 ES-MDA。

必须验证：

$$
C_f^{posterior}
$$

明显向：

$$
C_f^{true}
$$

收敛。

# 57. Coding rules

必须遵守：

### 57.1

不要进行与任务无关的大规模重构。

### 57.2

优先复用现有成熟代码。

### 57.3

不要为了“架构漂亮”制造十几层抽象。

### 57.4

所有公共 API 加：

```text
type hints
docstring
明确单位
```

### 57.5

所有物理变量明确单位。

例如：

```text
pressure: Pa
permeability: m²
conductivity: documented internal unit
time: s
rate: m³/s
```

禁止同一个变量有时使用：

```text
mD
```

有时使用：

```text
m²
```

却没有转换层。

### 57.6

算法必须 deterministic when seeded。

### 57.7

异常必须明确：

```text
PhysicsConvergenceError
FlashCalculationError
InvalidObservationError
AssimilationError
```

不要到处抛裸：

```python
ValueError
```

# 62. 最重要的产品原则

整个实现过程中必须始终遵守：

> 测点数据用于纠正模型，而不是替代模型。

以及：

> 第一版反演裂缝等效导流能力，不反演所有储层性质。

以及：

> 数据同化算法更新参数，压力场、饱和度场和组分场仍由守恒方程重新计算。

以及：

> 先证明 Scalar Cf 可以被可靠识别，再逐步增加空间自由度。

这是当前版本所有软件设计、算法选择和代码重构的最高优先级。
