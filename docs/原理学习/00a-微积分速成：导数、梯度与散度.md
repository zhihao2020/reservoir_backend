# 00a 微积分速成：导数、梯度与散度

> 一句话本质：**导数**就是「变化率」；**梯度**告诉你「往哪个方向走升得最快」；**散度**告诉你
> 「一个点是在往外漏，还是在往里吸」。第 01 章的达西定律和守恒方程，只用到这三样东西。
> 本章不考你微积分，只要你能「看懂符号、知道它想说什么」就够了——后面每一章都用得到。

**本章概念脉络**（每个概念都在解决一个问题，按出现顺序）：

| 概念 | 它解决的问题 |
|---|---|
| 导数 | 怎么度量「压力随时间变得多快」 |
| 偏导数 | 一个量同时随 x、y、z、t 变，怎么只看其中一个方向的变化 |
| 梯度 \(\nabla\) | 压力在空间里朝哪个方向升得最快（流体就朝反方向流） |
| 散度 \(\nabla\cdot\) | 某个点是在「往外漏」还是「往里吸」 |
| 链式法则 | 函数套函数时怎么求导（密度随压力变、压力随位置变） |

## 零、问题：岩心的压力在变，怎么度量「变得多快」？

整个油藏模拟，本质上就是在追一个问题：**压力、饱和度这些量，随着时间和空间怎么变。**
要描述「怎么变」，第一件事就是学会说「**变得多快**」——这就是导数。

> **形象化**：车上的速度表就是导数的实物。速度表不告诉你「车在哪」，只告诉你「位置在变，而且变得多快」。
> 导数就是数学里的速度表：给任意一个「在变的量」，它吐出这个量的变化快慢。

## 一、第一个工具：导数 = 割线斜率的极限

看一个最简单的例子：压力 \(p\) 随时间 \(t\) 变，记作 \(p(t)\)。我们想知道「这一刻压力涨得多快」。

**问题**：只看一个时刻，谈不上「变化」——变化需要两个时刻。怎么办？

**方法**：取一小段时间间隔 \(\Delta t\)（读作 delta t，就是「一小段 t」），看压力在这段里变了多少：

\[
\frac{p(t+\Delta t) - p(t)}{\Delta t}
\]

这叫**割线斜率**（一段直线从起点到终点的平均坡度）。它给的是「这一段里的**平均**变化率」。
想让这个平均值变成「**这一刻**的变化率」，就把 \(\Delta t\) 越缩越小，缩到无限小——记作：

\[
\frac{dp}{dt} = \lim_{\Delta t \to 0}\frac{p(t+\Delta t)-p(t)}{\Delta t}.
\]

其中：\(dp/dt\) 读作「p 对 t 的导数」；\(\Delta t\) 一小段时间间隔；\(\lim\) 极限（无限逼近的意思）。

> **形象化**：你在山路上开车，导航说「当前车速 40 km/h」——它不会等你开完一小时再告诉你，
> 而是看「极短一小段路程 ÷ 极短一小段时间」的比值。\(\Delta t\to 0\) 就是把这一段压到无限短。

**为什么油藏里天天见到它？** 守恒方程里那个 \(\partial p/\partial t\)（压力随时间的变化率）就是这个量。
下一章 01 的扩散方程，第一项就是它。

## 二、第二个工具：偏导数 = 一次只让一个变量变

压力不只随时间变，还随**位置**变：\(p(x,y,z,t)\) 同时依赖四个量。

**问题**：我想知道「沿着 x 方向，压力每走 1 米涨多少」，但 y、z、t 也在变，怎么把它们「按住」？

**方法**：**偏导数**——把其它变量都当成常数，只让 x 变。记作 \(\partial p/\partial x\)（读作「p 对 x 的偏导」，
弯的 \(\partial\) 就是提醒你「还有别的变量被按住了」）：

\[
\frac{\partial p}{\partial x} = \lim_{\Delta x\to 0}\frac{p(x+\Delta x, y, z, t) - p(x, y, z, t)}{\Delta x}.
\]

> **形象化**：一块山坡，你想知道「正东方向有多陡」。你不能问「这山有多陡」（那是把东南西北混在一起），
> 而要**只沿正东走一步**看升高多少——这就是对「东」的偏导数。四个方向各有一个偏导数。

**例**：压力 \(p(x)=20\times10^6 + 1000\,x\)（Pa，x 单位 m）。对 x 求偏导：

\[
\frac{\partial p}{\partial x} = 1000\ \mathrm{Pa/m}.
\]

意思：沿着 x 方向每前进 1 米，压力涨 1000 Pa。**偏导数是一个「变化率 + 方向」的东西**，单位是「量 / 长度」。

## 三、第三个工具：梯度 \(\nabla p\) = 把三个方向的偏导数打包

空间有三个方向 x、y、z。把三个偏导数摆成一个向量，就是**梯度**：

\[
\nabla p = \left(\frac{\partial p}{\partial x},\ \frac{\partial p}{\partial y},\ \frac{\partial p}{\partial z}\right).
\]

其中：\(\nabla\)（读作 nabla / del）就是「对空间三个方向各求一次偏导」的算符；\(\nabla p\) 是这三个偏导组成的向量。

**它解决什么问题？** 它指出**压力升高最快的方向**（梯度向量的指向 = 最陡上升方向，长度 = 那个方向的坡度）。

> **形象化**：你站在山坡上，梯度就是「从你脚下出发、往上爬得最陡的那条路」的方向和坡度。
> 水往低处流，就是**朝梯度的反方向**流——这就是达西定律的 \(-\nabla p\) 里那个负号的来历。

达西定律（第 01 章正式讲）说流体速度 \(\mathbf v\) 正比于压力梯度的**负值**：

\[
\mathbf v = -\frac{k}{\mu}\nabla p.
\]

其中：\(\mathbf v\) 达西速度（m/s）；\(k\) 渗透率、\(\mu\) 粘度（两个正数）；\(\nabla p\) 压力梯度（Pa/m）。
**负号**表示「从高压流向低压」——梯度指向压力升得最快的方向，流体反着走。

> **工程直觉：梯度有多大？** 页岩油案例里，压差约 1 MPa（\(10^6\) Pa）作用在约 0.15 m 上，
> \(\nabla p \approx 10^6/0.15 \approx 6.7\times10^6\) Pa/m。而后面要讲的重力效应只有约 759 Pa/m——
> **梯度项比重力项大四个数量级**，这就是「近井区粘性驱替完全压倒重力」这句话的数学来源。

## 四、第四个工具：散度 \(\nabla\cdot\mathbf v\) = 三个方向「各自流出多少」之和

梯度作用于一个**标量**（单个数，如压力 p），吐出「怎么变」的向量。但守恒方程里还有另一个算符，
作用于一个**向量**（如流速 \(\mathbf v\)），吐出「净流出」——这就是**散度**。

先想一维：流速 \(v(x)\) 只沿 x 方向。如果 \(v\) 在 x 处是 1，在 x+1 处是 3，说明越往右流得越快——
流体从 x 到 x+1 这段**多出来**了，也就是说这一小段在「往外漏」。散度就是度量这个「漏」的：

\[
\nabla\cdot\mathbf v = \frac{\partial v_x}{\partial x} + \frac{\partial v_y}{\partial y} + \frac{\partial v_z}{\partial z}.
\]

其中：\(\nabla\cdot\)（读作 div / 散度）就是把「每个方向的流速变化率」加起来；\(v_x,v_y,v_z\) 流速在三个方向的分量。

> **形象化**：把流场想成商场门口的人流。散度为正 = 出来的人比进去的多（这个门口在「往外吐人」）；
> 散度为负 = 进去的多（在「往里吸人」）；散度为零 = 进出平衡。**守恒**就是「整体进出加起来是 0」。

**例**：一维 \(v(x)=2x\)。则 \(\partial v/\partial x = 2 > 0\)——每一点都是净流出。对应画面：水管越走越粗，
每个截面都「盛不下」上游来水，于是往旁边漏。这就是散度在说话。

**为什么关键？** 守恒方程里那一项 \(\nabla\cdot(\rho\mathbf v)\)（质量净流出）就是这个散度。
第 02 章会把它变成「每个小方块几个面上进出的代数和」——那是散度的**离散版**。现在你只需记住：
**散度 = 一个点的净流出量**。

## 五、第五个工具：链式法则 = 函数套函数时怎么求导

油藏里经常是「套娃」：密度 \(\rho\) 随压力变，压力又随位置变，即 \(\rho(p(x))\)。想知道密度沿 x 怎么变，
就要「先看密度对压力的变化率，再看压力对位置的变化率，相乘」：

\[
\frac{d\rho}{dx} = \frac{d\rho}{dp}\cdot\frac{dp}{dx}.
\]

其中：\(\frac{d\rho}{dp}\) 密度对压力的变化率（压缩系数就藏在这里）；\(\frac{dp}{dx}\) 压力对位置的变化率。
**链式法则 = 层层变化率相乘**。

> **形象化**：油价每涨 1 块，菜价涨 2 毛（\(\frac{d菜}{d油}=0.2\)）；油价每桶涨 5 块（\(\frac{d油}{d桶}=5\)），
> 那每多进一桶，菜价涨 \(0.2\times5=1\) 毛。变化率一层层「传导」下去，就是相乘。

第 01 章的**相势** \(\Phi = p + \rho g z\)（重力把高度也折算进压力）在求导时，就要同时用到「梯度的线性叠加」
和链式法则。第 07b 章自然变量里的「变量折叠」，本质也是多变量链式法则——现在先有个印象即可。

## 六、回头看：一条「变化率」，四种包装

把本章五节摆在一起，它们其实都在说同一件事——**某个量对另一个量的变化率**：

| 情形 | 求什么 | 记号 | 油藏里对应 |
|---|---|---|---|
| 随时间变 | 压力涨多快 | \(\partial p/\partial t\) | 扩散方程的储量项 |
| 随位置变（一个方向） | 沿 x 每米涨多少 | \(\partial p/\partial x\) | 梯度的一个分量 |
| 三个方向一起看 | 朝哪升最快 | \(\nabla p\) | 达西定律的驱动力 |
| 一个向量场净流出 | 漏还是吸 | \(\nabla\cdot\mathbf v\) | 守恒方程的通量项 |

**不是四种新东西，是「变化率」在四种场合的写法。** 后面的章只是把这张表逐个用起来：
01 用 \(\nabla p\) 和 \(\nabla\cdot\) 写达西 + 守恒，02 把 \(\nabla\cdot\) 离散成矩阵。

## 七、代码对照

连续数学里的 \(\partial/\partial x\)，到了计算机里就是**差分**（前一点减后一点，除以间距）：

```python
# f 是沿 x 轴采样的数组，dx 是采样间距
dfdx = (f[1:] - f[:-1]) / dx    # 一阶差分，近似 ∂f/∂x
```

| 数学 | 代码 |
|---|---|
| \(\partial f/\partial x\) | `np.gradient(f, dx)` 或 `(f[1:]-f[:-1])/dx` |
| \(\nabla p\) | 对 x/y/z 各求一次偏导，拼成三个数组 |
| \(\nabla\cdot\mathbf v\) | 对 \(v_x,v_y,v_z\) 各求一次偏导再相加（第 02 章变成 `L @ p`） |
| 链式法则 | 先算内层导数、再算外层，最后相乘 |

第 00c 会专门讲「数值微分」和「有限差分」为什么能这么干、误差有多大。

## 八、小练习

```python
import numpy as np

# 1) 竖直压力场 p = 20e6 + 1e5 * z（z 向上），梯度该是 +1e5 Pa/m 朝上
z = np.linspace(0.0, 0.30, 31)              # 0 到 0.30 m
p = 20.0e6 + 1.0e5 * z
grad_p = np.gradient(p, z)                  # 近似 dp/dz
print("|grad_p| ≈", float(np.max(np.abs(grad_p))), "Pa/m  (应≈1e5)")

# 2) 静止流体的压力按静水压分布：越深越大，dp/dz = -rho_g。
#    相势 Phi = p + rho_g*z 把重力折算进去，两项抵消 → 梯度≈0（无流动）
rho_g = 1.0e5
p_hydro = 20.0e6 - rho_g * z              # 静止：压力向下增
Phi = p_hydro + rho_g * z
grad_Phi = np.gradient(Phi, z)
print("max|grad_Phi| ≈", float(np.max(np.abs(grad_Phi))), " (应≈0，两项抵消)")

# 3) 数值导数验证 d(x^2)/dx = 2x（中心差分）
x = 3.0
for h in (1e-2, 1e-6):
    d = ((x + h) ** 2 - (x - h) ** 2) / (2 * h)   # (f(x+h)-f(x-h))/(2h)
    print(f"h={h:g}  d(x^2)/dx @ x=3 = {d:.6f}  误差 {abs(d - 2*x):.2e}")
```

第二个结果应接近 0：`p + rho_g*z` 里两项随 z 的变化率正好抵消，这正是 01 章「静止时 \(\nabla p=-\rho g\nabla z\)、流速为 0」的由来。

## 九、章末测试题

**1.** 判断：「梯度 \(\nabla p\) 指向压力**降低**最快的方向。」

<details><summary>答案与解析</summary>

错。梯度指向压力**升高**最快的方向。流体才朝降低方向走，所以达西定律里是 \(-\nabla p\)。负号别丢。

</details>

**2.** \(p(x,y) = 20\times10^6 + 1000\,x - 500\,y\)，写出 \(\nabla p\)，并说流体大致往哪个方向流。

<details><summary>答案与解析</summary>

\(\nabla p = (1000,\ -500)\)（Pa/m）。流体朝 \(-\nabla p = (-1000,\ 500)\) 走：朝 −x 和 +y 的合成方向，即从高压流向低压。

</details>

**3.** 一维 \(v(x)=3\)（常数流速），它的散度是多少？物理上说明什么？

<details><summary>答案与解析</summary>

\(\partial v/\partial x = 0\)，散度为 0。流速处处相同意味着「进来多少就出去多少」，没有净流出也没有净流入——
一段等粗水管里匀速流动的水，就是这样既不漏也不吸。

</details>

**4.** 相势 \(\Phi = p + \rho g z\) 里，\(\nabla z\) 是什么向量？为什么静止时（压力只受重力作用）\(\nabla\Phi=0\)？

<details><summary>答案与解析</summary>

\(\nabla z = (0,0,1)\)：z 向上为正，所以 \(\nabla z\) 就是指向正上方的单位向量。
静止时越深压力越大，且 \(\nabla p = -\rho g\,\nabla z\)（往下走 1 米压力涨 \(\rho g\)），
代入得 \(\nabla\Phi = -\rho g\nabla z + \rho g\nabla z = 0\)。相势处处相等 ⇒ 无流动，这就是「相势」统一判断流向的根据。

</details>

**5.** 用链式法则：\(\rho = \rho_0(1+c_r p)\)（流体被压、密度线性涨），\(p(x)=10^6 x\)。求 \(d\rho/dx\)。

<details><summary>答案与解析</summary>

\(\frac{d\rho}{dp} = \rho_0 c_r\)，\(\frac{dp}{dx}=10^6\)，所以 \(\frac{d\rho}{dx}=\rho_0 c_r\cdot 10^6\)。
密度随 x 的变化 = 密度对压力的变化率 × 压力对 x 的变化率，两层变化率相乘。

</details>
