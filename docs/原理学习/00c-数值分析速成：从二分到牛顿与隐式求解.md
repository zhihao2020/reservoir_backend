# 00c 数值分析速成：从二分到牛顿与隐式求解

> 一句话本质：计算机只会**离散的加减乘除**；「数值方法」就是把连续、无穷的问题，改写成**有限步的加减乘除**。
> 牛顿法是「猜一个、用切线修」，隐式是「让未来和现在一起定」，收敛判据是「看误差够不够小」。
> 这一章是后面 07、07b 章的「工具箱总纲」——它们每天都在用这几样东西。

**本章概念脉络**（每个概念都在解决一个问题，按出现顺序）：

| 概念 | 它解决的问题 |
|---|---|
| 为什么要数值方法 | 连续微分方程，计算机算不了 |
| 二分法 → 牛顿法 | 方程 \(f(x)=0\) 怎么解 |
| 多元牛顿 + Jacobian | 成千上万个未知数一起怎么解 |
| 直接法 LU vs 迭代法 GMRES | 那个大线性方程组怎么解得又快又省 |
| 有限差分 | 导数没有公式时怎么近似 |
| 显式 vs 隐式（前向/后向欧拉）+ CFL | 时间怎么一步步往前推 |
| 收敛判据（残差范数） | 怎么知道「解好了」 |

## 零、问题：计算机算不了连续的东西

前两章给的是**连续**的数学：导数是一个极限，微分方程处处成立。但计算机只会离散的加减乘除——
它没法「取极限」，只能对**有限个点**做**有限步**运算。

**方法**：把连续的方程，换成「有限个点上、有限步内」能算的近似。这一步叫**离散化**。
第 02 章是把**空间**离散成格子，本章聚焦另一类：**解方程**（求根、解线性方程组、时间推进）怎么离散。

> **形象化**：计算机是一台只会「+ − × ÷」的超级计算器。你要它算 \(\sqrt2\)，它不会「看」，只能
> 一遍遍猜、一遍遍修正，直到够准。数值方法就是设计「怎么猜、怎么修」的套路。

## 一、第一个工具：解方程 \(f(x)=0\) → 二分法，再升级到牛顿法

油藏里到处是「找满足某条件的值」：泡点压力、稳态压力、牛顿迭代的根…… 本质都是解 \(f(x)=0\)。

### 1.1 二分法：靠谱但慢

**问题**：求 \(\sqrt2\)，即解 \(f(x)=x^2-2=0\)。

**方法**：若已知解在 \([1,2]\) 之间（因为 \(1^2-2<0<2^2-2\)），取中点 1.5，看 \(f(1.5)=0.25>0\)，
说明解在 \([1,1.5]\)。每步把区间**砍一半**。10 步后区间缩到原来的 \(1/2^{10}\approx1/1000\)。

> **形象化**：在一排书里找一本「编号恰好等于某个值」的书，每次都翻到中间那本、按编号大小决定往左还是往右。
> 稳，但每次只砍一半，慢。

### 1.2 牛顿法：用切线，越接近越快

二分法太慢（每步只砍半）。**牛顿法**用更聪明的信息——**切线**：

\[
x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}.
\]

其中：\(f'(x_k)\) 函数在 \(x_k\) 处的斜率（切线坡度）。

**直觉**：不知道根在哪，就在当前点画切线，看切线和 x 轴的交点在哪，把它当下一个猜测。

求 \(\sqrt2\)（\(f=x^2-2,\ f'=2x\)），从 \(x_0=1\) 出发：

| 步 | \(x_k\) | 误差 |
|---|---|---|
| 0 | 1 | 0.414 |
| 1 | 1.5 | 0.0858 |
| 2 | 1.4167 | 0.00245 |
| 3 | 1.414216 | 0.000002 |

看误差列：**每步的「正确位数」几乎翻倍**。这叫**二次收敛**——接近根时快得吓人。

> **深一层：为什么是「二次」？** 切线是 \(f\) 的一阶近似，误差只能来自二阶项。把 \(f(x^*)=0\) 在 \(x_k\) 处
> 泰勒展开到二阶再整理，误差满足 \(e_{k+1}\propto e_k^2\)——误差每步被**平方**，所以位数翻倍。
> 但前提是**初始猜测别离根太远**，太远切线会指错方向、发散。

## 二、第二个工具：多元牛顿 + Jacobian = 导数的「多变量版」

油藏不是解一个 \(x\)，是解**成千上万个未知数**（每格一个压力、饱和度、组成……）。把未知数堆成向量
\(\mathbf x\)，方程堆成向量 \(\mathbf R\)（每格一条守恒方程），要解的是：

\[
\mathbf R(\mathbf x) = \mathbf 0.
\]

牛顿法照样成立，只是「导数」从斜率变成一张**矩阵**——**Jacobian 矩阵** \(J\)：

\[
J_{ij} = \frac{\partial R_i}{\partial x_j},
\qquad
J\,\delta = -\mathbf R,\qquad \mathbf x \leftarrow \mathbf x + \delta .
\]

其中：\(J_{ij}\) 第 i 条残差方程对第 j 个未知数的偏导（「动一下 \(x_j\)，\(R_i\) 变多少」）；\(\delta\) 修正量。

> **形象化**：一元牛顿是「在一条曲线上画切线」。多元牛顿是「在一个高维曲面上画切平面」，找切平面和
> 零水平面的交点。Jacobian 就是那个「切平面的坡度」，只不过它是一整张表。

**关键**：实际**从不显式求 \(J^{-1}\)**（又慢又不稳），而是每步解一个线性方程组 \(J\delta=-R\)。
所以「解线性方程组」是牛顿迭代里的核心子步骤——下一节就讲它。

## 三、第三个工具：解大线性系统 → 直接法 LU vs 迭代法 GMRES

牛顿每步都要解 \(J\delta=-R\)，其中 J 是 \(10^4\sim10^5\) 阶的稀疏矩阵（第 00b）。怎么解？

### 3.1 直接法（LU / 高斯消元）

**方法**：像消元一样，把 A 分解成 L（下三角）和 U（上三角），再顺序代换求解。**精确**（算到机器精度），
但有填充：稀疏矩阵消元过程中会「填出」很多新的非零，存储和计算都可能暴涨。

> **形象化**：LU 是「把方程一个个彻底理清」，一步到位给精确答案，但「理清」的过程要打很多草稿（填充）。

### 3.2 迭代法（GMRES）

**方法**：不追求一次精确，而是**猜一个解、慢慢逼近**：每次迭代让残差 \(Ax-b\) 更小一点，直到够小就停。
GMRES 就是一类常用的迭代法（Krylov 子空间方法）。它**便宜**（每步只做几次矩阵乘），但不保证总是快——
对「病态」的矩阵（对流主导、非对称）可能收敛很慢或停转，这时要**预条件**（把方程组先变形成更好解的样子）。

> **形象化**：LU 是「精确称重」，GMRES 是「逐步逼近到秤的指针够稳」。后者快，但指针可能晃很久——预条件就是
> 先把秤调稳。

**本仓库怎么选**（`forward.py` 的 `_solve_linear`）：先试 GMRES（快）；不行就上 pyamg 的代数多重网格
**预条件** + GMRES；再不行才退回 `spsolve` 直接 LU 兜底。**先便宜后精确**，是工程上的标准打法。

## 四、第四个工具：导数没有公式 → 有限差分

牛顿法要 Jacobian（一阶偏导）。有的偏导好推（通量对压力，解析可算），有的极难（闪蒸对组成）。难推的怎么办？

**方法**：用「导数 = 割线斜率的极限」直接**数值**算。中心差分：

\[
f'(x) \approx \frac{f(x+h) - f(x-h)}{2h},\qquad h\ \text{很小，如}\ 10^{-6}.
\]

其中：\(h\) 扰动步长。把 x 扰动一点点，看 f 变多少，除以扰动——就是导数。

> **形象化**：不知道一座山的坡度公式，就**在山前、山后各探一脚**，用两点高度差除以距离。够近就够准。
> 这就是「数值微分」。07 章对闪蒸项就是这么做的：把 \((p,z)\) 扰动 \(10^{-6}\) 看残差变多少。

**工程上的分工**（07 章正式用）：**哪里推导收益大就解析，哪里复杂就差分**。通量导数解析（快且准），
闪蒸导数差分（稳健、免推错）。两种混用。

## 五、第五个工具：时间怎么推 → 显式 vs 隐式（前向/后向欧拉）+ CFL

油藏要一步步往前推时间。守恒方程形如 \(\frac{dy}{dt}=f(y)\)（y 是某个状态）。核心选择只有一件事：
**右边的 \(f(y)\) 用哪个时刻的 y？**

### 5.1 显式（前向欧拉）：用现在算未来

\[
y_{n+1} = y_n + \Delta t\cdot f(y_n).
\]

**优点**：右边全是已知的 \(y_n\)，直接代数算出 \(y_{n+1}\)，**不用解方程组**，每格独立更新。
**死穴**：步长 \(\Delta t\) 一大就振荡、发散、出现负的饱和度。看 \(dy/dt=-y,\ y(0)=1\)：

\[
\text{显式：}y_{n+1} = (1-\Delta t)\,y_n.
\]

\(\Delta t=3\) 时系数是 \(-2\)：\(y\) 正负交替、越跳越大，**爆炸**。即使 \(\Delta t=1.5\)，系数 \(-0.5\)，
不爆炸但符号来回翻——而真解 \(y=e^{-t}\) 是**永远为正、单调下降**的，符号翻来翻去就是错。

### 5.2 隐式（后向欧拉）：让未来和现在一起定

\[
y_{n+1} = y_n + \Delta t\cdot f(y_{n+1}).
\]

右边的 \(f\) 用**新时刻** \(y_{n+1}\)——它自己还没求出来，所以每步要**解方程**。看 \(dy/dt=-y\)：

\[
y_{n+1} = y_n - \Delta t\, y_{n+1}\ \Rightarrow\ y_{n+1} = \frac{y_n}{1+\Delta t}.
\]

任意 \(\Delta t>0\)，系数 \(\frac{1}{1+\Delta t}<1\)，永远为正、单调下降——**无条件稳定**。

> **形象化**：显式是「看着昨天每个水箱的水位，各自决定今天搬多少」，一次搬太多就搬成负数；
> 隐式是「所有人先商量好今天的水位，再一起搬」，可以一次搬很多，代价是每次商量（解方程）都很贵。

**CFL / 稳定性直觉**：显式步长有个上限，大致是「一个格子的孔隙体积 ÷ 流进它的流量 × 允许的变化」。
**近井格子流量大、孔隙体积小，所以显式在井边步长最小**——这正是 07 章为什么宁可用「每步更贵的全隐式」
去换「大步长」的原因。

## 六、第六个工具：怎么知道解好了 → 收敛判据（残差范数）

迭代法（牛顿、GMRES）都是「越来越近」，那什么时候停？看**残差**——把当前的解代回方程，还差多少没满足。

**残差范数** \(\|\mathbf R\|\)：把残差向量「大小」量一量（最简单用 2-范数：各分量平方和开根）。判断：

\[
\|\mathbf R\| < \mathrm{tol}\cdot \|\mathbf R_0\| .
\]

其中：\(\mathbf R_0\) 初始残差；\(\mathrm{tol}\) 容差（本仓库组分/自然变量用 `_EOS_NEWTON_RTOL = 0.1`，
黑油用 \(10^{-3}\)）。意思是「残差降到初始的 tol 倍以下就算收敛」。

> **工程直觉：收敛 ≠ 物理正确。** 收敛只说明「把方程解出来了」。方程本身写错（重力方向、迎风方向、
> 平凡解）时，牛顿照样能收敛到一个**错的**答案。所以排查「结果不对」先看残差写没写对；
> 排查「不收敛/很慢」才看 Jacobian。这个区分 07 章测试题 8 还会考。

## 七、回头看：一条「离散化」，七个套路

| 情形 | 假设/需求 | 方法 | 新增工具 |
|---|---|---|---|
| 解 f(x)=0，只要一个数 | 区间已知 | 二分法 | 无 |
| 解 f(x)=0，要快 | 有导数、初值近 | 牛顿法 | 切线、二次收敛 |
| 解多元 R(x)=0 | 成千未知数 | 多元牛顿 | Jacobian |
| 解 Jδ=−R | J 大而稀疏 | LU 直接 / GMRES 迭代 | 稀疏、预条件 |
| 求导数 | 无公式或太繁 | 有限差分 | 扰动 h |
| 时间推进 | 大步长、稳定 | 隐式（后向欧拉） | 解方程换稳定 |
| 判断收敛 | 迭代停止 | 残差范数 + 容差 | 范数 |

**不是七种新东西，是「把连续问题改成有限步」这条路上，按不同障碍选的七个工具。** 07 章把它们串成
全隐式求解器，07b 章把它们用在自然变量 FIM 上。

## 九、小练习

```python
import numpy as np

# 1) 牛顿法求 sqrt(2)：f=x^2-2, f'=2x
x = 1.0
for k in range(6):
    f = x * x - 2.0
    fp = 2.0 * x
    x = x - f / fp
    print(f"k={k}  x={x:.10f}  误差={abs(x - np.sqrt(2)):.2e}")

# 2) 显式 vs 隐式（后向欧拉）解 dy/dt=-y, y(0)=1, dt=3, 6 步
y_ex = 1.0; y_im = 1.0; dt = 3.0
for _ in range(6):
    y_ex = (1.0 - dt) * y_ex          # 显式：系数 -2，符号交替、越跳越大
    y_im = y_im / (1.0 + dt)          # 隐式：系数 1/4，永远正、单调降
print(f"显式 y={y_ex:+.1f}  (真值应≈0，显式已爆炸)  隐式 y={y_im:.6f}")

# 3) 有限差分验证 d(sin)/dx = cos @ x=1
x0 = 1.0
h = 1e-6
d = (np.sin(x0 + h) - np.sin(x0 - h)) / (2 * h)
print(f"d(sin)/dx @ 1 = {d:.10f}  真值 cos(1) = {np.cos(1.0):.10f}")
```

第 1 步你会看到误差位数逐行翻倍（二次收敛）；第 2 步显式项正负交替、绝对值指数增长，隐式项稳定收敛到 0。

## 十、章末测试题

**1.** 牛顿法为什么是「二次收敛」？

<details><summary>答案与解析</summary>

切线是 f 的一阶近似，误差只来自二阶项。误差满足 \(e_{k+1}\propto e_k^2\)，每步被平方，所以正确位数翻倍。
前提是初值离根够近。

</details>

**2.** 二分法每步把区间缩小多少？10 步后精度如何？

<details><summary>答案与解析</summary>

每步砍半，10 步后区间是原来的 \(1/2^{10}\approx 1/1000\)。可靠（只要区间两端异号）但线性收敛，慢。

</details>

**3.** 判断：「隐式法一定比显式法准。」

<details><summary>答案与解析</summary>

错。隐式更**稳定**（步长大也不发散），但每一步的**精度**仍是一阶（欧拉法都一样）。稳和准是两回事：
隐式是「不会崩」，不是「更精确」。要更高精度得用更高阶的格式。

</details>

**4.** \(\|\mathbf R\|=10^{-9}\)，容差 tol=\(10^{-8}\)。说明什么？能说明结果物理上正确吗？

<details><summary>答案与解析</summary>

说明残差已降到容差以下，**数值上收敛了**。但不能说明物理正确——方程本身写错时（重力方向、迎风方向、
平凡解）牛顿照样收敛到错解。物理正确性要靠守恒检查、单元算例、真值对照（07 章测试题 8）。

</details>

**5.** 解 \(dy/dt=-y\)，显式欧拉在 \(\Delta t=1.5\) 和 \(\Delta t=3\) 下各是什么行为？

<details><summary>答案与解析</summary>

系数 \(1-\Delta t\)：\(\Delta t=1.5\) 时是 \(-0.5\)，正负交替但绝对值衰减（不爆炸但明显错，真解恒正）；
\(\Delta t=3\) 时是 \(-2\)，正负交替且绝对值翻倍，发散爆炸。稳定边界是 \(|1-\Delta t|<1\)，即 \(\Delta t<2\)。

</details>
