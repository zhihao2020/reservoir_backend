# 02 网格与有限体积离散

> 把连续的 \(\nabla\cdot(k\lambda\nabla\Phi)\) 变成稀疏矩阵乘向量。对应
> [`src/core/cartesian.py`](../../src/core/cartesian.py)、[`src/programs/mesh.py`](../../src/programs/mesh.py)、
> [`src/programs/forward.py`](../../src/programs/forward.py) 里的 `tpfa_matrix`、`_mobility_divergence_matrix`、`_phase_divergence_matrix`。

## 一、直观理解

实验室是 30 cm 的立方体。代码把它切成 \(n_x\times n_y\times n_z\) 个长方体单元，
每个单元一个压力、一套饱和度——**格心（cell-centered）** 有限体积。

有限体积的核心只有一句话：对单元做积分，散度变成面上的通量之和。守恒就是「进出面的代数和」。

两点通量近似（TPFA）再加一条：每个面的通量只取决于该面两侧两个单元的势差。
正交笛卡尔网格上这是一致的；歪网格才需要 MPFA 等多点格式。本软件只用正交网格。

> **形象化**：每个单元是一个水箱，相邻水箱之间有一根水管。水管的粗细就是传导率 \(T\)，
> 两个水箱的水位差就是势差，流量 = 粗细 × 水位差。整个网格就是一张水管网，求解就是「让每个水箱进出平衡」。

## 二、网格几何

`CartesianGrid(nx, ny, nz, dx, dy, dz, origin)`：`dx` 可以是标量（均匀）或长度为 `nx` 的数组。

平坦下标（和协议、NumPy `ravel` 一致）：

\[
\mathrm{cell} = k\cdot n_y\cdot n_x + j\cdot n_x + i.
\]

可视化时 `reshape_ijk` 变成 `(nz, ny, nx)`，这样 `field[k, j, i]` 的 `k` 是层号，`k=0` 是底层（\(z\) 最小）。
**不要**用 `(nx, ny, nz)` 去 reshape，仪表盘会把轴看反。

```python
from src.core.cartesian import CartesianGrid
grid = CartesianGrid.uniform(size_m=(0.30, 0.30, 0.30), spacing_m=0.02)
# nx = round(0.30/0.02) = 15，与 shale_oil 案例同类
```

| 方法 | 作用 |
|---|---|
| `index(i,j,k)` / `ijk(cell)` | 下标互转 |
| `cell_centers()` | `(n_cells, 3)` 格心坐标 |
| `cell_volumes()` | \(V_i = \Delta x_i\Delta y_j\Delta z_k\) |
| `neighbors(cell)` | 最多 6 个正交邻居 |
| `locate_cell(x,y,z)` | 点落在哪个单元（最大面落入最后一格） |
| `segment_cells(p0, p1)` | 线段穿过的单元（井轨迹） |
| `face_area_x/y/z` | 含外边界的面面积 |
| `center_distance_x/y/z` | 相邻格心距 \(\frac12(\Delta_i+\Delta_{i+1})\) |
| `scaled(lambda_xyz)` | 几何相似放大到矿场 |

外边界默认 **无流（Neumann 零通量）**：进出只通过井。

> **工程直觉**：15³ = 3375 个格子，每格 2 cm。井筒半径 3 mm，已经和格子是同一个量级——
> 这会让井模型（第 04 章）处在适用边缘。网格越细不一定越准，要看井半径和格子的比例。

## 三、TPFA 传导率

单元 \(i\) 与邻居 \(j\) 共享面积 \(A_{ij}\)、格心距 \(d_{ij}\)。单相面通量

\[
Q_{ij} = T_{ij}(p_i - p_j),
\qquad
T_{ij} = \frac{k_{ij}\,A_{ij}}{d_{ij}}\,\lambda_{ij}.
\]

渗透率必须用 **调和平均** \(k_H = 2k_1 k_2/(k_1+k_2)\)。代码 `_harmonic` / `_harmonic_mean`
故意不加 \(10^{-30}\) 这种 epsilon——在渗透率夹紧下限附近，加性 epsilon 会让均值偏 30%。

> **形象化**：两段半格长的岩石串联，就是两个电阻串联。总电阻相加 → 等效电导是调和平均。
> 一段通、一段堵，水流由堵的那段说了算。
>
> **工程直觉**：\(k_1=1,\ k_2=0.01\) 时，调和平均 0.0198，算术平均 0.505——算术平均高估了 25 倍。
> 反演得到的 \(k\) 场如果有高对比，用错平均会让「隔层」完全失效。

\(x\) 方向均匀网格：

\[
T_{i+1/2} = k_H\,\lambda_f\,\frac{\Delta y\,\Delta z}{\tfrac12(\Delta x_i+\Delta x_{i+1})}.
\]

组装成图拉普拉斯 \(L\)：对角 \(L_{ii}=\sum_j T_{ij}\)，非对角 \(L_{ij}=-T_{ij}\)。于是 \((L p)_i\) 是流出单元 \(i\) 的净体积通量，
即 \(L p \equiv \nabla\cdot(-k\lambda\nabla p)\) 的有限体积形式。

`tpfa_matrix` 里流度取两侧**算术平均**（只用于单相压力解）；输运用的算子取**迎风**流度（下一节）。
热路径上的 `_tpfa_matrix_vec` 是同一公式的向量化版本。

## 四、迎风与按相势迎风

饱和度是双曲型输运：信息沿流动方向传播。面上的流度要取**上游**单元的值：

\[
Q_{ij} = T^{\mathrm{geo}}_{ij}\,\lambda_{\mathrm{up}}\,(\Phi_i-\Phi_j),
\qquad
\lambda_{\mathrm{up}} = \begin{cases}\lambda_i & \Phi_i > \Phi_j\\ \lambda_j & \text{否则}\end{cases}
\]

> **形象化**：顺风闻味。你闻到的是上风处的味道；下风处有没有花，不影响你闻到什么。
> 一个空格子（\(\lambda=0\)）挨着一个满格子，流体该从满的流向空的——必须用满格子的流度，否则通量为零、锋面永远推不动。

势差给定后，散度对流度 \(\lambda\) 是线性的：\(\mathrm{div} = A\lambda\)。`_mobility_divergence_matrix(grid, k, Φ)` 返回这个稀疏 \(A\)，
迎风方向按传入的势 \(\Phi\) 判断。牛顿 Jacobian 里出现 `A @ diag(dλ/dS)`（对饱和度求导）和
`_upwind_tpfa_matrix_vec(grid, k, λ, Φ)`（对势求导，固定迎风方向）。

**气相要按它自己的相势迎风**。气相势 \(\Phi_g = p + \Delta\rho\,g\,z\)：

```text
def _phase_divergence_matrix(grid, k, p, rho_g):
    # A_g @ lam == div(-k lam^up grad(p + rho_g z))
    return _mobility_divergence_matrix(grid, k, p + rho_g * z)
```

液相、水相按 \(p\) 迎风，气相按 \(\Phi_g\) 迎风。压力均匀时，上格 \(\Phi_g\) 比下格高 \(\Delta\rho g\Delta z\)，
所以上格是上游：上格有气就往下格流，上格没气就不流。

> **复查修正**：旧代码写成 `A_g = A - rho_g * A_grav`，其中 `A_grav` 是按「假压力 \(-z\)」迎风的重力算子，
> 永远取**下面**那格的流度。`rho_g < 0`（气上浮）时这恰好是上游，没问题；
> 但 `rho_g` 改成正值（CO₂ 下沉）以后，它变成了取**下游**流度：
> 上格有气、下格没气时重力通量是 0（气沉不下去）；下格有气、上格没气时，上格反而「流出」本不存在的气。
> 两格算例已写成回归测试 `tests/test_gravity_upwind.py`。修复后压力项和重力项合成一个相势，一次判断上游。

## 五、测点映射与碰撞轴加密

[`build_mesh`](../../src/programs/mesh.py)：

1. 按 YAML 的 `nx, ny, nz` 建均匀网格。
2. 每个测点 `locate_cell` 落到一个单元。
3. 若两个测点落到同一单元：沿它们坐标差最大的轴把该方向格数 +1，重建网格，直到一对测点一格。
4. 两测点坐标完全相同直接报错；某一轴加到 256 仍分不开也报错。
5. 井：`WellSpec.trajectory` 折线用 `segment_cells` 采样（步长为最小边长的 1/4），得到完井单元集合；
   踵→趾向量存进 `WellMap.directions`，供 Peaceman 判断直井/水平井。

反演把 \(k/\phi\) 参数化在**测点**上再克里金到全场，所以「一测点一格」保证每个测点是独立参数。

> **工程直觉**：加密是按「碰撞」自动发生的。如果你发现输出网格不是 YAML 里写的 15³，先看测点表里有没有两个点挨得比 2 cm 还近。

## 七、小练习

```python
import numpy as np
from src.core.cartesian import CartesianGrid
from src.programs.forward import tpfa_matrix, _phase_divergence_matrix

grid = CartesianGrid.uniform((0.30, 0.30, 0.30), 0.10)
print("nx,ny,nz,n_cells =", grid.nx, grid.ny, grid.nz, grid.n_cells)
print("cell (1,0,0) flat index =", grid.index(1, 0, 0))  # 1
print("reshape shape =", grid.shape_ijk)                 # (3, 3, 3)

k = np.full(grid.n_cells, 3.0e-17)
L = tpfa_matrix(grid, k, np.ones(grid.n_cells))
print("L @ 1 (should be ~0) =", float(np.max(np.abs(L @ np.ones(grid.n_cells)))))

# 两格竖柱：只有上格有气，均匀压力，气比油重
col = CartesianGrid(nx=1, ny=1, nz=2, dx=0.1, dy=0.1, dz=0.1)
A_g = _phase_divergence_matrix(col, np.full(2, 1e-15), np.full(2, 20e6), 759.0)
print("net outflow [bottom, top] =", A_g @ np.array([0.0, 1.0]))  # top > 0, bottom < 0
```

`L @ 1 ≈ 0` 说明组装满足「内部面成对抵消、外边界无流」。竖柱算例里上格净流出为正、下格为负，说明气在往下沉。

## 八、章末测试题

**1.** \(k_1 = 1\) mD、\(k_2 = 0.01\) mD 的两格之间，面渗透率用调和平均和算术平均各是多少？哪个物理上对？

<details><summary>答案与解析</summary>

调和平均 \(2\times1\times0.01/1.01\approx 0.0198\) mD；算术平均 0.505 mD。调和平均对：两半格串联，总阻力相加。
算术平均会让 0.01 mD 的隔层几乎不起作用。

</details>

**2.** 为什么 `L @ ones` 应该等于 0？如果不是 0，最可能是哪里错了？

<details><summary>答案与解析</summary>

常数压力没有压差，不会有流动，散度为 0；数学上是图拉普拉斯的每行和为 0。
不为 0 通常是对角元和非对角元没配对（某个面只加了一边），或者下标 `i/j/k` 与 reshape 的轴顺序不一致。

</details>

**3.** 两格水平相邻，\(p_1 = 20.01\) MPa、\(p_2 = 20.00\) MPa，格 1 \(\lambda=0\)、格 2 \(\lambda=500\)。迎风面流度取多少？通量是多少？

<details><summary>答案与解析</summary>

流动从 1 到 2，上游是格 1，取 \(\lambda=0\)，通量为 0。
这是对的：格 1 里没有这一相，不可能流出这一相。如果取算术平均（250），就会凭空从格 1 流出流体，格 1 饱和度变负。

</details>

**4.** 计算传导率：\(k=2.96\times10^{-17}\) m²，\(\lambda=1/(2\times10^{-3})\)，格子 2 cm 立方。\(T\) 是多少？10 kPa 压差下的面通量呢？

<details><summary>答案与解析</summary>

\(T = k\lambda A/d = 2.96\times10^{-17}\times500\times(0.02)^2/0.02\approx 2.96\times10^{-16}\) m³/(Pa·s)。
通量 \(2.96\times10^{-16}\times10^4\approx 3\times10^{-12}\) m³/s。和注入速率 \(2.5\times10^{-10}\) 比，一个面要约 80 倍的压差才能单独输走全部注入量——近井压力堆高是必然的。

</details>

**5.** 竖直相邻两格，格心高差 0.1 m，压力相等，`rho_g = 759` Pa/m。气相势差是多少？哪格是上游？

<details><summary>答案与解析</summary>

\(\Phi_{\mathrm{top}}-\Phi_{\mathrm{bot}} = 759\times0.1 = 75.9\) Pa，上格势高，是上游，气从上往下流。
要让流动反向（气往上走），下格压力必须比上格高 75.9 Pa 以上。

</details>

**6.** 读代码找错：`A_g = A - rho_g * _mobility_divergence_matrix(grid, k, -z)`，`rho_g > 0`。在只有上格有气、压力均匀时，这个算子算出的重力通量是多少？为什么？

<details><summary>答案与解析</summary>

是 0。第二个算子按「压力」\(-z\) 迎风，\(-z\) 在下格更大，于是它把**下格**当上游，取下格的气相流度（0）。
乘上 \(-\rho_g\) 后通量方向反成向下，但流度仍是下格的——也就是下游流度。这就是复查中修掉的逆风重力问题。

</details>

**7.** 两个测点坐标分别是 (0.100, 0.150, 0.150) 和 (0.105, 0.152, 0.150)，网格 15³（2 cm 一格）。`build_mesh` 会加密哪个方向？

<details><summary>答案与解析</summary>

两点落在同一格（x 都在 0.10–0.12，y 都在 0.14–0.16）。坐标差 \(|\Delta x|=0.005\) 最大，所以 `nx` +1 后重建网格，
直到两点分到不同格子。

</details>

**8.** 判断：「把 `nx` 从 15 加到 30，井附近一定更准。」

<details><summary>答案与解析</summary>

不一定。格子从 2 cm 变成 1 cm 后，Peaceman 等效半径 \(r_e\approx0.2\Delta x = 2\) mm 会**小于**井筒半径 3 mm，
\(\ln(r_e/r_w)<0\)，井指数公式失效（第 04 章测试题 6）。细化网格要同时检查井模型的适用条件。

</details>
