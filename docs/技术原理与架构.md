# 技术原理与架构

> 面向自学的整体原理文档 + 技术路线图 + 架构图。
> 本文档解释「软件用什么原理、怎么组织、现在走到哪、接下来往哪走」。

## 一、软件做什么

**实验室三维场重构**：从稀疏的测点/井观测（压力、饱和度、注采量）反推整个三维网格的
**压力 p、饱和度 sw/so/sg、孔隙度 φ、渗透率 k**。页岩油 CO₂ 吞吐场景：注入井注纯 CO₂，
生产井采油，重构出 CO₂ 羽流（自由气 + 溶解气）与岩石场。

一句话数据流：

```
case.yaml + observations.csv + wells.csv + series.csv
        │
        ▼
  克里金插值（测点 → 全场 p/sat）  →  反演 k/φ  →  前向模拟 sat（质量守恒）  →  再反演 k/φ  →  输出场
```

### 2.3 前向模型层级

```
forward_saturations(model=...)
├── black_oil                 # 非混相三相（IMEX 式），CO₂ 是永久自由气相
├── compositional             # 溶液气：CO₂ 溶进油 (C = sg/Bg + Rs·so)，过饱和析出
├── compositional_two         # 双组分 PR EOS 闪蒸 (p, sw, z)，z = 烃内 CO₂ 摩尔分数

├── compositional_full        # 14 组分全闪蒸
└── compositional_two_kinetic # 动力学溶解 + Carlson 残余捕集（非润湿气相驱替，P0）
```

   (当前只跑一遍；阶段 7 目标是迭代到 k/φ 与羽流自洽)

## 三、技术原理

### 3.1 网格与几何（core/cartesian.py）

`CartesianGrid(nx, ny, nz, extent)`：规则六面体网格。提供格心坐标、体积、各方向面、邻居索引。
TPFA（两点通量近似）用相邻格子的调和平均渗透率 + 面面积/距离算传导率，组装成稀疏拉普拉斯矩阵。

### 3.2 克里金插值（pressure.py / saturation.py）

从 16–27 个测点插值到全场。克里金是**最优线性无偏估计**：用协方差/变差函数给测点加权，
平滑插值。压力/孔隙度/渗透率是平滑全局场，克里金足够（误差 0.1–3%）；饱和度是局部突变场
（羽流），克里金结构性漏报/过报（4.3%）——这是前向模型要解决的问题。

### 3.3 反演（rock.py: invert_rock）

从插值出的 p/sat 场反演 k/φ：构造正演残差（散度 vs 井源），牛顿迭代最小化残差，
带平滑正则化（P1 权重）与相渗联合反演（P2）。shale_oil 案例 k 误差已降到 3.1%。

### 3.4 前向模型（forward.py）

用质量守恒的饱和度场替代克里金插值。**压力方程是总烃摩尔平衡**（OPM/MRST 组分标准，非总流度
体积平衡）：

```
r_p = accum·(N − N0) − q_N + A_g@(λg/v_g) + A@(λl/v_l)
```

其中 `accum = φ·V/dt`、`N = (1−sw)/(V·v_g + (1−V)·v_l)`（总摩尔密度）、
`q_N = qg/V_CO2_STD + qo/v_l`（摩尔井源）、`A_g = A − rho_g·A_grav`（气相浮力）。摩尔平衡在
`v_g ≠ v_l` 时也**守恒油组分**（油 = 总摩尔 − CO₂，修复了体积平衡的油泄漏），并让泡点穿越更
光滑（不再失速）。压力方程还含**压缩性** `accum·ct·(p−p0)`（压掉注入井过量再循环）与**总重力
通量** `−rho_g·(A_grav@λg)`。

- **黑油**：IMPES 或全隐式，三相各自 Darcy 流。
- **溶液气**：CO₂ 溶解进油（Rs），守恒 `C = sg/Bg + Rs·so`，全隐式 (p, sw, C)。
- **组分**：PR EOS 闪蒸决定气/液劈分，(p, sw, z) 全隐式，组分流度 `y·λg/v_g + x·λl/v_l`。
- **动力学 + 捕集**：溶解是 k_diss 弛豫（非瞬时），气相独立非润湿相，Carlson 残余捕集
  （sg_max 滞回）让气不快速泄回。

### 3.5 相平衡（core/pr_eos.py）

**Peng-Robinson 状态方程**：`P = RT/(v−b) − a/(v²+2bv−b²)`，用临界性质 + 偏心因子算 a/b，
混合规则算混合物的 a_mix/b_mix。**Rachford-Rice 闪蒸**：给定 (P, z)，迭代求气相摩尔分数 V 和
相组成 x/y（Wilson 初始 K 值 + 逸度更新）。泡点溶解度 Rs_sat(p) 由闪蒸的气液边界求得。
Peneloux 体积平移修正超临界 CO₂ 密度（390→590 kg/m³）。

### 3.6 井模型（rock.py: peaceman_wi）

**Peaceman 井指数**：`WI = 2π kh h / (ln(re/rw) + skin)`，把井筒压力与网格压力通过等效半径
耦合，算注采量。各向异性（kv/kh）与方向（直井/水平井）分情况；geofac 是 GEM GEOMETRY 几何因子。

### 3.7 相似换算（similarity.py）

实验室（30 cm）与矿场（300 m）的几何-运动相似准则，跨尺度换算长度/体积/流径。

### 3.8 联调协议（protocol.py / udp.py / input_tcp.py）

协议 v2（已冻结）：TCP 入站测点/注采步进（HELLO/READY/STEP/ACK/NAK），UDP 出站反演场
（MANIFEST/FIELD/RESULTS，带 CRC32 与序号，可检测丢包）。
