# 技术原理与架构

> 面向自学的整体原理文档 + 技术路线图 + 架构图。
> 本文档解释「软件用什么原理、怎么组织、现在走到哪、接下来往哪走」。

## 一、软件做什么

**实验室三维场重构**：从稀疏的测点/井观测（压力、饱和度、注采量）反推整个三维网格的
**压力 p、饱和度 sw/so/sg、孔隙度 φ、渗透率 k**。页岩油 CO₂ 吞吐场景：注入井注纯 CO₂，
生产井采油，重构出 CO₂ 羽流（自由气 + 溶解气）与岩石场。

一句话数据流：

```
case.yaml + observations.csv + wells.csv + series.csv
        │
        ▼
  克里金插值（测点 → 全场 p/sat）  →  反演 k/φ  →  前向模拟 sat（质量守恒）  →  再反演 k/φ  →  输出场
```

## 二、总体架构

### 2.1 模块结构

```

├── core/            # 纯计算，无 IO
│   ├── cartesian.py # 三维 Cartesian 网格（格心、体积、面、邻居）
│   ├── pr_eos.py    # Peng-Robinson 状态方程 + 闪蒸（Rachford-Rice）
│   ├── units.py     # 单位换算（mD ↔ m² 等）

│   ├── rock.py      # 相渗（Corey/表格 + Carlson 捕集）、Peaceman 井、反演 invert_rock
```

## 三、技术原理

### 3.1 网格与几何（core/cartesian.py）

`CartesianGrid(nx, ny, nz, dx, dy, dz)`：规则六面体网格。提供格心坐标、体积、各方向面、邻居索引。
平坦下标 `cell = k*ny*nx + j*nx + i`，可视化 reshape 成 `(nz, ny, nx)`。
TPFA（两点通量近似）用相邻格子的调和平均渗透率 + 面面积/距离算传导率，组装成稀疏拉普拉斯矩阵。
详见 [原理学习/02-网格与有限体积离散](原理学习/02-网格与有限体积离散.md)。

### 3.2 克里金插值（pressure.py / saturation.py）

从 16–27 个测点插值到全场。普通克里金是**最优线性无偏估计**：用指数变差函数的协方差给测点加权，
带 \(\sum w_i=1\) 约束。实现里变差函数可水平/垂直各向异性，并用留一法报告 RMSE；矩阵奇异时降级 IDW。
压力/孔隙度/渗透率是平滑全局场，克里金足够（误差 0.1–3%）；饱和度是局部突变场
（羽流），克里金结构性漏报/过报（4.3%）——这是前向模型要解决的问题。
详见 [原理学习/03-克里金插值](原理学习/03-克里金插值.md)。

### 3.3 反演（rock.py: invert_rock）

从插值出的 p/sat 场反演静态 \(k/\phi\)。未知量参数化在**测点**上（\(\log k\) 与 logit \(\phi\)），
用预计算克里金权重投到全场；残差是达西散度 − 井源 + \(\phi c_t V\partial_t p\)，外加均值约束与
近邻平滑。优化器是 `scipy.optimize.least_squares(..., method="trf")`（带界约束的信赖域最小二乘），
散度对 \(\log k\) 的 Jacobian 解析，不是「全场牛顿迭代每个格子的 k」。
`black_oil_3phase` 走分相守恒 + 可选 Corey 联合反演。shale_oil 案例 k 误差约 3.1%。
详见 [原理学习/05-岩石参数反演](原理学习/05-岩石参数反演.md)。

### 3.4 前向模型（forward.py）

用质量守恒的饱和度场替代克里金插值。`compositional` 是 14 组分 PR 闪蒸，压力方程是总烃摩尔平衡
（不是总流度体积平衡）：

```
r_p = accum·(N − N0) − q_N + A_g@(λg/v_g) + A@(λl/v_l)
```

其中 `accum = φ·V/dt`、`N = (1−sw)/(V·v_g + (1−V)·v_l)`（总摩尔密度，EOS 体积已含流体压缩性）、
`q_N = qg/V_CO2_STD + qo/v_l`（摩尔井源）、`A = A(p)`、`A_g = A(p + rho_g·z)`。
`A_g` 由 `_phase_divergence_matrix` 构造：气相按**气相势** \(p+\Delta\rho g z\) 取迎风流度，
`rho_g` 是气相相对液相的浮力头（Pa/m，>0 下沉）；液相以 `p` 为参考势，不另加重力。
（旧写法 `A − rho_g·A_grav` 在 `rho_g>0` 时取了下游流度，复查中已修，见原理学习 02、07。）
摩尔平衡在 `v_g ≠ v_l` 时也**守恒油组分**（油 = 总摩尔 − CO₂），并让泡点穿越更光滑。
流体压缩性含在 EOS 的 `N(p)` 里；岩石压缩性项 `accum·ct·(p−p0)` 只出现在溶液气压力步和动力学支路，
双组分/多组分摩尔残差里没有（已知缺口）。

- **黑油**：全隐式三相 Darcy，CO₂ 是永久自由气。
- **溶液气**：CO₂ 溶解进油（Rs），守恒 `C = sg/Bg + Rs·so`，全隐式。
- **组分**：PR EOS 闪蒸决定气/液劈分，(p, sw, z) 全隐式。
- **动力学 + 捕集**：溶解是 k_diss 弛豫，气相独立非润湿相，线性残余捕集（`sg_free = 2·sg − sg_max`，Carlson/Land 的简化）。

详见 [原理学习/07-前向模型：从黑油到组分](原理学习/07-前向模型：从黑油到组分.md)。

### 3.5 相平衡（core/pr_eos.py）

**Peng-Robinson 状态方程**：`P = RT/(v−b) − a/(v²+2bv−b²)`，用临界性质 + 偏心因子算 a/b，
混合规则算混合物的 a_mix/b_mix。**Rachford-Rice 闪蒸**：给定 (P, z)，迭代求气相摩尔分数 V 和
相组成 x/y（Wilson 初始 K 值 + 逸度更新）。泡点溶解度 Rs_sat(p) 由闪蒸的气液边界求得。
Peneloux 体积平移修正超临界 CO₂ 密度（390→590 kg/m³）。
详见 [原理学习/06-PR状态方程与闪蒸](原理学习/06-PR状态方程与闪蒸.md)。

### 3.6 井模型（rock.py: peaceman_wi）

**Peaceman 井指数**：`WI = 2π kh h / (ln(re/rw) + skin)`，把井筒压力与网格压力通过等效半径
耦合，算注采量。各向异性（kv/kh）与方向（直井/水平井）分情况；geofac 是 GEM GEOMETRY 几何因子。
相对渗透率为 Corey 或表格（Stone I），可选 Carlson 捕集。详见 [原理学习/04-相对渗透率与井模型](原理学习/04-相对渗透率与井模型.md)。

### 3.7 相似换算（similarity.py）

实验室（30 cm）与矿场（300 m）的几何-运动相似准则，跨尺度换算长度/体积/流径。
详见 [相似换算](相似换算.md) 与 [原理学习/08-管线与在线会话](原理学习/08-管线与在线会话.md)。

### 3.8 联调协议（protocol.py / udp.py / input_tcp.py）

协议 v2（已冻结）：TCP 入站测点/注采步进（HELLO/READY/STEP/ACK/NAK），UDP 出站反演场
（MANIFEST/FIELD/RESULTS，带 CRC32 与序号，可检测丢包）。在线会话用宽度为 2 的滑动窗口 + 后台反演线程。
字节规范见 [接口协议](接口协议.md)，走查见 [联调指南](联调指南.md)。
