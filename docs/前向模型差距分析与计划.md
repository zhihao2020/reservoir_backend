# 前向模型差距分析与分步计划

> 定位：三维场重构程序（页岩油 CO₂ 吞吐）的**前向模型**（P3）——用质量守恒的饱和度场替代克里金插值，
> 再喂给 k/phi 反演。本文盘点前向模型当前差距，制定可执行的分步计划。
> 现状基线（已实跑）：密度 EOS 化 + Peneloux + 死油基 + rho_g 符号 + geofac 已落地，但 30 天仍是 **0% 自由气**（真值 30%）。

## 一、差距清单

按「阻塞程度 × 影响面」排序。

### A. 物理机理（决定羽流对不对）——**核心阻塞**

| # | 差距 | 状态 | 影响 |
|---|---|---|---|
| A1 | 非润湿气相驱替（CO₂ 当独立气相体积驱替油相 + 溶解源项） | ❌ 未做 | 0% 自由气的根因，见 [[非润湿气相驱替设计]] |
| A2 | 相密度 EOS 化 + Peneloux + 死油基 | ✅ 本轮已做 | 消除 1.56× N/C/通量高估 |
| A3 | rho_g 符号（CO₂ 比油重应下沉） | ✅ 上轮已做 | 浮力方向 |

### B. 正确性（守恒/单位）——审计发现，未处理

|---|---|---|---|

| B2 | 压力方程缺**可压缩性** `∂φ/∂t = φ·ct·∂p/∂t` | ❌ 未做 | 超低渗封闭储层，压缩储能一阶重要 |
| B3 | 压力方程缺**总重力通量**（气相重力项只在 CO₂ 方程，没进总平衡） | ❌ 未做 | 总质量不守恒 |

## 二、分步计划

### 阶段 1：物理机理（非润湿气相驱替）——先让自由气能累积
- 1.1 P0 独立气相 Darcy + 体积驱替（sg 独立守恒，不再由平衡闪蒸反推）
- 1.2 P1 溶解源项（动力学 k_diss，注入 CO₂ 先以气相存在、沿路才溶）
- 1.3 P2 重力 + EOS 密度（复用 A2/A3）
- **里程碑**：单步诊断确认 sg 单调增长、so 下降、正反馈（so↓→λl↓→溶解通量↓）占优

### 阶段 2：稳健性——让 30 天能跑完且收敛
- 2.1 修泡点失速（自适应 dt + 更保守回退 + 变量切换）
- 2.2 质量守恒回归测试（ΣφV·Δ(sg/Bg + Rs·sl) ≈ Σ(q_g + Rs·q_l)·dt）
- **里程碑**：30 天 conv 完成，无 `did not converge` warning

### 阶段 3：正确性（守恒/单位）——让物理可信
- 3.1 压力方程改摩尔守恒（B1，油/重烃守恒）
- 3.2 评估/加可压缩性（B2，对照 forward_pressure 已有的 φ·ct 项）
- 3.3 压力方程补总重力通量（B3）
- **里程碑**：油相 + 总质量守恒，无泄漏

### 阶段 4：验证——对 GEM 全场
- 4.1 30 天底部羽流 vs `cmg_fields.csv`（bottom k0-2 → 0.456）
- 4.2 sg_sum（→527）、注入井 sg（→0）、压降/注速自洽
- **里程碑**：so/sg 逐层误差显著低于克里金 4.3%

### 阶段 5：性能——让反演能迭代
- 5.1 EOS 闪蒸表 + 落盘缓存（已有部分）+ 解析 Jacobian 或局部变量切换
- 5.2 目标：30 天 < 1 分钟
- **里程碑**：反演循环可跑多次

### 阶段 6：集成与测试——让程序能用起来
- 6.1 接入 CLI（`--model compositional_two/three/full/nonwetting`）
- 6.2 组分模型回归测试
- 6.3 per-well geofac（WellSpec 加 geofac 字段）
- 6.4 评估 `forward.model` 默认开启
- **里程碑**：`python -m src shale_oil/case.yaml --model X` 可跑，pytest 覆盖

### 阶段 7：闭环（反演耦合，可选）
- 7.1 forward → re-invert 定点迭代到收敛（当前只跑一遍）
- **里程碑**：k/phi 与羽流自洽收敛

## 三、建议先做

**阶段 1（P0）+ 阶段 2.1**，因为：
1. 物理机理是唯一能解决 0% 自由气的路；
2. 泡点失速不修，连 30 天都跑不完，物理对不对都验不了。

预计阶段 1–4 是「让前向模型能复现羽流」的主线；阶段 5–6 是「让它能用起来」；阶段 7 是「让闭环真正闭合」。
