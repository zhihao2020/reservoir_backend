公开联调只保留 [`example/`](../example/)。`python -m src example/case.yaml` 可直接跑通，不依赖 GEM。

| 案例 | 目录 | 网格 | 反演模型 | 用途 |
|---|---|---|---|---|
| **页岩油 CO₂** | `example/` | 15×15×15 | black_oil_3phase | 真实 GEM 数据联调，27 测点 / 5 井 / 120 拍 |

`examples/shailoil.dat` 是 GEM 源数据（15×15×15、14 组分 CO₂ 页岩油），`example/` 的测点/井/时序取自它；仅作溯源，不需要 GEM 即可使用 CSV。

## 页岩油 CO₂ 案例（`example/`）

真实 GEM 导出数据（120 月、27 测点、5 井），用于 CO₂ 页岩油吞吐联调与场重构：

- **数据**：GEM Peng-Robinson 14 组分模型（20 MPa、120 ℃、注纯 CO₂）。27 个测点在
  **底层 k=0/1/2**（3×3×3，与井位对齐），5 口井（INJ 注入 + PROD1–4 采油）。
- **岩石均质**（k 恒 0.03 mD、φ 恒 0.05），故 `inversion.k_homogeneous: true` 跳过病态
  k 反演、直接用常数 k0。
- **CO₂ 组分追踪**：`black_oil.rs_slope: 9.84e-6` → 输出 `rs`（溶解气比 Rs≈187）与
  `co2`（总 CO₂ 组分 = sg+Rs·so）两个场。
- 测点/井下标顺序：测点 = `probes.csv` 行序（0=P_3_3_15 … 26=P_13_13_13），
  井 = `wells.csv` 行序（0=INJ，1–4=PROD1–4）。
- 前向饱和度默认 `forward.model: none`。CLI `--model` 只开放 `black_oil`。

离线跑通：

```bash
python -m src example/case.yaml -o results/shale_oil
```

在线联调（协议 v2 冻结不变）：

```bash
# 终端 1：接收端
python example/receive_fields.py --lab-port 9001 --field-port 9002

# 终端 2：后端（真实 GEM 数据，27 测点 / 5 井 / 120 拍）
python -m src example/case.yaml --tcp-port 9000 --ip 127.0.0.1 \
    --lab-port 9001 --field-port 9002

# 终端 3：调用端（读 example 时序，逐拍发 STEP）
python example/send_steps.py --host 127.0.0.1 --port 9000
```

## 案例文件

| 文件 | 内容 |
|---|---|
| `src.so` | Linux 后端动态库（pack-linux 写入） |
| `case.yaml` | 网格、测点/井引用、反演模型、黑油参数、相似比 |
| `probes.csv` | `id,x_m,y_m,z_m` |
| `wells.csv` | `id,kind,x_m,y_m,z_m,x2_m,y2_m,z2_m` |
| `observations.csv` | `time_s,probe,quantity,value,unit` |
| `series.csv` | `time_s,well,pw_pa,q_m3s,qw_m3s,qo_m3s,qg_m3s` |
| `send_steps.py` | 调用端（TCP STEP） |
| `receive_fields.py` | 接收端（UDP lab/field） |
| `requirements.txt` | numpy / scipy / PyYAML |
| `README.md` | 使用说明 |

## `case.yaml` 字段参考

```yaml
geometry:
  origin_m: [0.0, 0.0, 0.0]
  extent_m: [0.30, 0.30, 0.30]
  nx: 15
  ny: 15
  nz: 15
rock:
  phi0: 0.05
  k0_md: 0.03
probes:
  file: probes.csv
  observations: observations.csv
wells:
  file: wells.csv
  series: series.csv
inversion:
  model: black_oil_3phase
  k_homogeneous: true
forward:
  model: none                   # 默认跳过前向；CLI 仅 --model black_oil
black_oil:
  mu_w_pa_s: 5.0e-4
  mu_o_pa_s: 2.0e-3
  mu_g_pa_s: 2.0e-5
  Swc: 0.0
  Sor: 0.0
  Sgc: 0.0
  ct_1pa: 1.2e-9
  rs_slope: 9.84e-6
well:
  rw: 0.003
  skin: 0.0
  kv_kh: 0.2
similarity:
  field_length_m: 300.0
  field_width_m: 300.0
  field_height_m: 30.0
  field_flow_path_m: 150.0
  model_flow_path_m: 0.15
  volume_basis: reservoir
```

完整解析逻辑见 `src/core/lab_case.py`；单位自动换算见 `src/core/units.py`。
