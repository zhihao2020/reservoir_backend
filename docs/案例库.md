# 案例库

`examples/` 下的案例都能用 `python -m src <case.yaml> -o <out>` 直接跑通，不依赖 GEM。
除 `online/`（GEM shailoil 合成重放）与 `shale_oil/`（真实 GEM 导出数据）外，其余都由
`scripts/gen_synthetic_case.py` 生成（确定性，可重跑）。

| 案例 | 目录 | 网格 | 反演模型 | 耗时 | 用途 |
|---|---|---|---|---|---|
| 秒级联调 | `small/` | 8×8×8 | black_oil_3phase | 秒级 | 首次跑通、TCP/UDP 联调 |
| 2D | `twod/` | 30×30×1 | black_oil_3phase | 秒级 | 单层切片、快速调试 |
| 多模型对照 | `model_compare/` | 10×10×10 | total_mobility + black_oil_3phase | 秒级 | 验证 `inversion.model` 两条路径 |
| 离线文件 | `offline/` | 20×20×20 | black_oil_3phase | 数秒~十秒 | 展示 `-o` 的 npz/npy/csv/json 输出 |
| 在线对接 | `online/` | 60×60×60 | black_oil_3phase | 单步较慢 | TCP/UDP 完整流程、GEM shailoil 数据 |
| **页岩油 CO₂** | `shale_oil/` | 15×15×15 | black_oil_3phase | 秒级（k_homogeneous） | **真实 GEM 数据联调**、CO₂ 组分追踪（rs/co2 输出） |

`examples/shailoil.dat` 是 GEM 源数据（15×15×15、14 组分 CO₂ 页岩油），`online/` 与
`shale_oil/` 的测点/井/时序取自它；仅作溯源，不需要 GEM 即可使用 CSV。

## 页岩油 CO₂ 案例（`shale_oil/`）

这是**真实 GEM 导出数据**（120 月、27 测点、5 井），用于 CO₂ 页岩油吞吐项目的联调与场重构：

- **数据**：GEM Peng-Robinson 14 组分模型（20 MPa、120 ℃、注纯 CO₂）。27 个测点在
  **底层 k=0/1/2**（3×3×3，与井位对齐），5 口井（INJ 注入 + PROD1–4 采油）。
- **岩石均质**（k 恒 0.03 mD、φ 恒 0.05），故 `inversion.k_homogeneous: true` 跳过病态
  k 反演、直接用常数 k0。
- **CO₂ 组分追踪**：`black_oil.rs_slope: 9.84e-6` → 输出 `rs`（溶解气比 Rs≈187）与
  `co2`（总 CO₂ 组分 = sg+Rs·so）两个场，用于追踪 CO₂ 去向（自由气 + 溶解气）。
- 测点/井下标顺序：测点 = `probes.csv` 行序（0=P_3_3_15 … 26=P_13_13_13），
  井 = `wells.csv` 行序（0=INJ，1–4=PROD1–4）。

离线跑通：

```bash
python -m src examples/shale_oil/case.yaml -o results/shale_oil
```

在线联调（见 [`联调指南.md` §5](联调指南.md)）：

```bash
python -m src examples/shale_oil/case.yaml --tcp-port 9000 --ip 127.0.0.1 --lab-port 9001 --field-port 9002
python examples/online/send_steps.py --host 127.0.0.1 --port 9000 \
    --probes examples/shale_oil/probes.csv --wells examples/shale_oil/wells.csv \
    --observations examples/shale_oil/observations.csv --series examples/shale_oil/series.csv
```

## 运行

```bash
# 离线（文件 I/O）
python -m src examples/small/case.yaml -o results/small

# 在线（TCP 入 + UDP 出），四个终端，见 docs/联调指南.md
python -m src examples/online/case.yaml --tcp-port 9000 --ip 127.0.0.1 --lab-port 9001 --field-port 9002
```

## 案例文件

每个案例目录含：

| 文件 | 内容 |
|---|---|
| `case.yaml` | 网格、测点/井引用、反演模型、黑油参数、相似比（见下） |
| `probes.csv` | `id,x_m,y_m,z_m` |
| `wells.csv` | `id,kind,x_m,y_m,z_m,x2_m,y2_m,z2_m` |
| `observations.csv` | `time_s,probe,quantity,value,unit` |
| `series.csv` | `time_s,well,pw_pa,q_m3s,qw_m3s,qo_m3s,qg_m3s` |

`model_compare/` 没有 `case.yaml`，而是两个 `total_mobility.yaml` / `three_phase.yaml`
共享同一组 CSV，`inversion.model` 不同。

## `case.yaml` 字段参考

```yaml
geometry:
  origin_m: [0.0, 0.0, 0.0]     # 网格原点，m
  extent_m: [0.30, 0.30, 0.30]  # 模型边长，m（固定 0.30 m 立方）
  nx: 8                         # 也可 dx/dy/dz 逐轴（非均匀）
  ny: 8
  nz: 8
rock:
  phi0: 0.05                    # 孔隙度先验均值
  k0_md: 0.03                   # 渗透率先验均值，mD
probes:
  file: probes.csv              # 或 items: [{id,x,y,z}, ...]
  observations: observations.csv
wells:
  file: wells.csv
  series: series.csv
interpolation:
  method: kriging               # 固定 kriging（无需配置，可省略）
inversion:
  model: black_oil_3phase       # total_mobility | black_oil_3phase
  relperm: [nw, no, ng, krw_end, kro_end, krg_end]  # 三相相对渗透率（可选）
  k_homogeneous: false          # 均质岩石：跳过病态 k 反演、直接用常数 k0
  k_smoothness: 2.0             # k 反演的空间平滑正则化强度
forward:
  model: none                   # none | black_oil | compositional | fcm（也可 --model 传入）
black_oil:
  mu_w_pa_s: 5.0e-4
  mu_o_pa_s: 2.0e-3
  mu_g_pa_s: 2.0e-5
  Swc: 0.0
  Sor: 0.0
  Sgc: 0.0
  ct_1pa: 1.2e-9
  rs_slope: 0.0                 # 溶解气比 Rs=rs_slope·p；>0 时输出 rs/co2 场
  bo_slope: 0.0                 # 油相溶胀系数（先默认 0，不溶胀）
well:
  rw: 0.003
  skin: 0.0
  kv_kh: 0.2
similarity:
  field_length_m: 300.0          # 矿场几何，用于 --field-port 换算
  field_width_m: 300.0
  field_height_m: 30.0
  field_flow_path_m: 150.0       # 非等比例时必需；默认取 field_length_m
  model_flow_path_m: 0.15
  volume_basis: reservoir        # standard | reservoir | actual
experiment:
  name: small
```

> 完整解析逻辑见 `src/core/lab_case.py`；单位自动换算见 `src/core/units.py`（CSV 里
> `unit` 列可写 MPa/kPa/bar/psi、mL/min、m3/d 等，`_m` 后缀列直接给 SI）。

## 关于"多模型对照"

`model_compare/` 的两个 yaml 用**完全相同的**合成数据，分别走 `total_mobility` 与
`black_oil_3phase`。合成数据是平滑解析场（无真实非均质性），因此两者都收敛到先验均值
（`k≈0.03 mD`、`phi≈0.05`）——这是**正确**行为，不是 bug。要看到两模型差异，需要
"相富"数据：多拍、饱和前沿演化明显、相分离流量（如 `online/` 的 GEM shailoil 数据）。
此案例的价值是验证 `inversion.model` 两条路径都能跑、输出结构一致。
