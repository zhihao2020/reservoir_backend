# 非润湿气相驱替前向模型实施方案（③）

> 目标：让组分前向模型复现 GEM 真值的**底部羽流**（自由气集中在底层 k=0–2，sg≈0.46–0.98）。
> 状态：**已实施 P0**（`_forward_compositional_two_kinetic_saturations` + Carlson 捕集），但方向部分修正——
> 单步诊断确认「非润湿气相 + 捕集」让气留在注入井（sg≈0.057）不沉底；再循环诊断（注入井油流 = 净注入
> 5.9×）指出**过度溶解的根因是压力方程缺压缩性**，不是气相输运。真正落地的是**摩尔平衡压力方程**
> （见 `压力方程逐项对照.md` 与 `技术原理与架构.md`），非润湿气相捕集仍保留为动力学溶解分支。

## 0. 一句话诊断（已实跑坐实）

- 平衡组分模型：注入 CO₂ 全部溶进油相，被溶解通量 `x·r_co2·λl`（r_co2≈146 放大）随油带走，油相**永不饱和** → 0% 自由气。
- 真值：注入 CO₂ 超量（160 PV > 溶解度 ~139 PV），约 13–30% 以**独立气相**析出，且**气相体积驱替油相**（so↓ → λl↓ → 溶解通量↓ → CO₂ 累积），沉到底部。
- 根因是**输运机理**：当前模型把 CO₂ 当「溶解组分随油平流」，缺「独立气相体积驱替 + 溶解源项」这 MRST co2lab 风格的一块。

## 1. 架构：非润湿气相驱替 + 溶解源项

参考 `reference_projects/MRST-main/autodiff/ad-blackoil` 与 `co2lab` 的非润湿相处理。

**主变量**：`(p, sw, sg)`。液相 `sl = 1 − sw − sg`（油 + 溶解 CO₂）。备选 `(p, sw, z, Cd)` 动力学变量（把溶解当独立状态，`Cd` 以 `k_diss` 弛豫到平衡）。

**相 Darcy 速度**（含重力）：
```
v_w = -k λw(sw) ∇p
v_l = -k λl(sl) ∇p                     # 液相为参考密度
v_g = -k λg(sg) (∇p + ρ_g g ∇z)        # 气相非润湿、浮力（ρ_g = (ρ_CO2-ρ_oil)g，EOS 推导）
```

**守恒方程**：
```
压力(体积):   ∇·(λt ∇p + λg ρ_g ∇z) = q_vol
水:           ∂(φ sw)/∂t + ∇·v_w = q_w
CO₂组分:      ∂(φ (sg/Bg + Rs sl))/∂t + ∇·(v_g/Bg + Rs v_l) = q_g + Rs q_l
溶解源(动力学): ∂(φ Cd)/∂t = k_diss (Rs_sat sl − Cd) − 溶解通量
```

**与当前模型的本质区别**：

| | 当前组分模型 | 非润湿气相驱替 |
|---|---|---|
| 主变量 | (p, sw, z) 单组分 C=z·N·V_STD | (p, sw, sg) 或 (p, sw, z, Cd) |
| 相劈分 | **平衡闪蒸**（瞬时，V(z,p) 定 sg/sl） | 气相是**独立状态**，溶解是**动力学源项** |
| 注入 | 注入 CO₂ 立即进溶解通量 | 注入 CO₂ 以**气相**进、体积驱替油相 |
| 反馈 | 自由气通量随 sg↑ 增大 → 气被排走（**负反馈**） | so↓ → λl↓ → 溶解通量↓ → CO₂ 累积（**正反馈**） |

关键：`sg` 是**独立主变量**，气相有自己的 Darcy 输运，不依附于平衡闪蒸；溶解是 `k_diss` 的源项，注入 CO₂ 先以气相存在、沿路才溶。这正是文档 §8.4「动力学溶解」想做的，但当时实现把气相通量用 `λg/Bg` 写进了 CO₂ 守恒、与溶解通量耦合在同一方程，负反馈（sg↑→λg↑→气被排走）压过了正反馈（so↓→λl↓→溶解通量↓）。新架构要把气相输运与溶解输运**解耦**，让「体积驱替」这一项显式进入。

## 2. 实施步骤（每步可测试）

### P0 — 独立气相 Darcy + 体积驱替（核心）
- 主变量 `(p, sw, sg)`，液相 `sl = 1-sw-sg`。
- 气相输运独立：`v_g = -k λg(sg)(∇p + ρ_g g ∇z)`，用现有 `_mobility_divergence_matrix` + `_gravity_divergence_matrix`。
- 关键：sg 的**累积项**独立守恒 `∂(φ sg/Bg)/∂t + ∇·(v_g/Bg) = q_g − 溶解源`，不再由平衡闪蒸反推。
- 验证：单步注入 → sg 单调增长、油相 so 相应下降（体积驱替），守恒 `ΣφV·Δ(sg/Bg) ≈ Σq_g·dt − 溶解量`。

### P1 — 溶解源项（动力学，MRST co2lab 非润湿相思路）
- 溶解状态 `Cd`，`∂(φ Cd)/∂t = k_diss(Rs_sat·sl − Cd) − ∇·(Rs v_l)`。
- 注入 CO₂ 在注入井停留（停留时间 ≪ 1/k_diss）保持气相，沿路才溶。
- 验证：标定 k_diss 使注入井附近自由气停留、底部有析出（对照 GEM 的「注入即达底部」时间尺度）。

### P2 — 重力 + 密度（复用本轮成果）
- `ρ_g = (ρ_CO2-ρ_oil)g` 用 EOS（Peneloux 平移后）推导，非标量调参。
- 气相浮力 + 溶解 CO₂ 使油变重 → 沉底。
- 验证：自由气在井压差 + 重力下向底层 k=0–2 集中，而非散在 1857 格。

### P3 — 全 GEM 场验证
- 30 天跑 `shale_oil`：底部 k0-2 sg 均值 → 0.456、注入井 sg → 0、sg_sum → ~527。
- 对比 `cmg_fields.csv` 逐层。

### P4 — 性能与健壮性
- EOS 闪蒸瓶颈（当前 91 分钟/30天）：闪蒸表 + 解析 Jacobian 或局部变量切换。
- 泡点穿越失速：更保守的自适应 dt 策略。

## 3. 验证方案

1. `pytest` 全绿（新模型默认关闭，不影响现有 case）。
2. 守恒回归：`ΣφV·Δ(sg/Bg + Rs·sl) ≈ Σ(q_g + Rs·q_l)·dt`（净注入 = 累积）。
3. `--model nonwetting` 跑 shale_oil 30 天，对照真值 `[bottom 0.456, top 0.0815, inj 0, sg_sum 527]`。

## 4. 风险与开放问题

1. **正/负反馈博弈**（最核心）：sg↑ → λg↑（气排走，负）vs so↓ → λl↓ → 溶解通量↓（气累积，正）。必须让后者占优，否则退回「散在 1857 格 ~0.04」的老结果。P0 要先用单步诊断确认哪一项占优，再决定气相相对渗透率的处理（Corey vs GEM *SGT 表）。
2. **注入井 sg 目标**：§12 已更正真值注入井 sg=0（不是 0.71），所以 P0 不应追「注入井高饱和」，而应追「底部析出」。
3. **是否需要保留平衡闪蒸**：若 k_diss 足够小，动力学模型退化为平衡；需验证两者在极限下一致。
4. **性能**：气相输运独立 + 溶解状态 = 变量 +1，Jacobian 更大，需评估是否仍用块前代换。
