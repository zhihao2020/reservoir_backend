# 混相/组分前向模型设计（②）

> 页岩油 CO₂ 吞吐场重构——把自由气重构从「非混相黑油」升级为「混相/组分」模型。
> 状态：**已被 supersede**。实际落地的是**溶液气（solution-gas）两相模型**（`forward.py` 的
> `compositional`，组分 `C = sg/Bg + Rs·so`，CO₂ 溶于油 `Rs=rs_slope·p`），不是本文档的 FCM
> 单相方案。本文档保留作为 FCM 混相方案的原始设计参考（密度反转、相劈分后处理等思想仍适用）。

## 1. 背景与问题诊断（为什么必须换模型）

当前前向模型是**带溶解气的扩展黑油**（`forward.py` 的 `compositional`），本质仍是**非混相两相**：自由气（CO₂ 富相）和油相是两个不互溶的相，各有独立的相对渗透率与流度。

实测诊断（全部实跑确认）：

| 参数调整 | 自由气 sg 结果 | Newton 收敛 |
|---|---|---|
| 物理气体粘度 μg=2e-5 | 0.495（激波） | ❌ |
| 混合粘度 μg=2e-3 | 0.489（激波） | ❌ |
| 气体不动 μg=1e6 | 0.003（残余） | ✅ |
| 低气相端点 krg_end=0.01 | 0.487（激波） | ❌ |
| 线性相对渗透率 | 0.495（激波） | ❌ |

**根因**：非混相模型里，注入的 CO₂ 作为**自由气驱替油相**，形成 Buckley-Leverett 激波（活塞式驱替），激波前缘饱和度恒 ~0.5。而真值 sg=0.145 是**混相溶解**的结果——CO₂ 溶进油相（99.9% 溶解），自由气只是 0.1% 的残余，且靠**密度反转（CO₂ 富相更密）重力分异到底层**。调相对渗透率、粘度、FVF 都动不了激波，因为激波是两相分相流的固有属性。

**结论**：必须换模型。混相/组分模型不是「加参数」，而是把「两相分相流」换成「单相组分输运 + 相平衡」。

## 2. 物理事实（shale_oil 案例）

- CO₂ 在 20 MPa 下超临界、高度溶于油：**99.9% 注入 CO₂ 溶解**，自由气仅 0.1%。
- **密度反转**：CO₂ 富相（~800 kg/m³）比油相（~600 kg/m³）更密，**下沉到底层**（真值 sg 在 k=0–2 层 ~0.9，上层 ~0）。
- 重力分异是**快速过程**（实验室 30 cm 尺度，CO₂ 富相数小时沉降），在 30 天报告间隔内即达**稳态分异**——所以前向模型在每个报告时刻应给出「分异后的稳态」，而非瞬态。
- 溶解（相平衡）是报告分辨率的慢过程（数月）。

## 3. 模型选择：FCM（一阶接触混相）vs 全组分 EOS

| 方案 | 描述 | 优点 | 缺点 |
|---|---|---|---|
| **FCM（推荐）** | CO₂ 与油**全混相**（单相），CO₂ 是示踪剂浓度 c；有效粘度/密度用混合规则 | 简单、方程清晰、无激波、直接给密度反转 | 单相，无法直接给 sg（需后处理） |
| 全组分 EOS | Peng-Robinson 两相闪蒸，逐格算 K 值、相饱和度 | 最准确、直接给 sg/so | 大工程（EOS + 闪蒸 + 组分物性），计算重 |

**推荐 FCM**：本案例 CO₂ 高度溶解、接近全混相，FCM 已能刻画「溶解 + 密度反转 + 重力分异」三大关键；GEM 的 `sg`/`so` 可作为**后处理**从 CO₂ 浓度 c 反推（见 §5），不必跑完整 EOS。

## 4. FCM 方程

**变量**：压力 p、CO₂ 体积分数 c（0 ≤ c ≤ 1）。单相，含水可并作惰性相或忽略（sw=0）。

**有效物性（混合规则）**：

- 有效粘度（1/4 幂律，Todd-Longstaff 常用）：
  ```
  μ_eff(c) = ( c/μ_s^0.25 + (1-c)/μ_o^0.25 )^(-4)
  ```
  其中 μ_s 为纯 CO₂ 粘度、μ_o 为油粘度。（简化可用 μ_eff = μ_o · (μ_s/μ_o)^c 指数混合。）

- 有效密度（线性混合，含密度反转）：
  ```
  ρ_eff(c) = c·ρ_s + (1-c)·ρ_o          (ρ_s > ρ_o → CO₂ 富相更密)
  ```

**单相 Darcy 流（含重力）**：

```
v = - (k/μ_eff) · (∇p - ρ_eff·g·∇z)
∇·v = q_total                            (不可压缩总质量守恒)
```

**CO₂ 组分输运（示踪剂随总速度平流）**：

```
∂(φ·c)/∂t + ∇·(c·v) = q_co2
```

其中 `q_co2` 为 CO₂ 组分注入量（注入井纯 CO₂，q_co2 = qg；采出井 q_co2 = c·qo）。

**关键耦合**：ρ_eff(c) 进入压力方程（密度反转驱动 CO₂ 富相下沉），μ_eff(c) 进入流度——这就是「溶解 + 重力分异」的机理。

**求解策略（全隐式，复用现有框架）**：
1. 隐式解压力（总流度 k/μ_eff，含 ρ_eff 重力头）。
2. 隐式推进 CO₂ 浓度 c（后向欧拉 + Newton，复用 `_mobility_divergence_matrix` + gmres）。
3. 变量 c 有界 [0,1]，Jacobian 非零（μ_eff、ρ_eff 对 c 光滑单调），**规避现有 C 变量在欠饱和区的零 Jacobian 问题**——这正是 ③「换变量」的落地。

## 5. 相劈分（后处理，从 c 到 sg/so）

FCM 是单相，但 GEM 输出是两相饱和度。用**溶解度阈值**反推：

```
c  ≤ c_sat  →  sg = 0,            so = 1 - sw          （全溶解，欠饱和）
c  >  c_sat  →  自由气 sg = (c - c_sat)/(1 - c_sat)·(1-sw),  so = 1-sw-sg  （饱和，析出自由气）
```

`c_sat` 为溶解度（CO₂ 体积分数阈值，可用现有 `rs_eq_slope` 或标定）。这样 FCM 的浓度场 c 就能映射回 GEM 的两相饱和度场，直接与 `cmg_fields.csv` 对比。

## 6. 与现有前向模型的接口

- 复用：`_mobility_divergence_matrix`（散度算子）、`_gravity_divergence_matrix`（重力算子）、`_solve_linear`（gmres）、自适应子步、`_balance_well_rates`（闭合总源）。
- 新增 `forward_saturations(model="fcm")` 分支，或替换 `compositional` 分支。
- 参数扩展 `BlackOilParams`：`rho_s`/`rho_o`（相密度）、`mu_s`/`mu_o`（相粘度，已有 `mu_o`/`mu_g`）、`c_sat`（溶解度）。
- 输出不变（p/sw/so/sg/phi/k + rs/co2），wire 协议冻结不动。

## 7. 实施计划（分步，每步可测试）

1. **P0 — 物性混合 + 单相压力**：实现 `μ_eff(c)`、`ρ_eff(c)`，压力方程加入 ρ_eff 重力头。
2. **P1 — CO₂ 组分输运**：隐式推进 c（变量 c，后向欧拉 + Newton），验证有界、无激波。
3. **P2 — 相劈分后处理**：c → sg/so（溶解度阈值），跑 shale_oil 对比 `cmg_fields.csv`。
4. **P3 — 反演耦合**：用 FCM 输出的 sg/so 反演 k（复用 `_invert_static`），验证 k 不再被羽流污染。
5. **P4 — 标定与调参**：标定 `c_sat`、`ρ_s`、`μ_s` 使 sg 均值、底部羽流位置接近真值。

## 8. 验证方案

1. `python -m pytest -q` + `scripts/verify_examples.py` 全绿（FCM 默认关闭，不影响现有案例）。
2. 单步 FCM：无激波（c 平滑分布）、CO₂ 富相随 ρ_eff 下沉到底层。
3. `python -m src shale_oil/case.yaml -o results/shale_oil --model fcm`：sg 均值 ≈ 0.1–0.2（vs 当前激波 0.5、真值 0.145）、sg 集中底层 k=0–2、k 反演 CV 下降。
4. 质量守恒：累计注入 CO₂ ≈ 累计采出 + 组分在储量。

## 9. 风险与开放问题

- **溶解度阈值 c_sat 需标定**：GEM 数据无直接 c 场，需从「自由气体积/油体积」反推（类似之前 Rs 的估算）。
- **密度反转的符号**：ρ_s > ρ_o 才下沉，需确认 CO₂ 富相在 20 MPa 下的密度方向（GEM 真值羽流在底层支持 ρ_s > ρ_o）。
- **FCM 忽略相界面**：若 CO₂ 溶解不充分（局部 c 高），FCM 的全混相假设会偏差，需评估是否退到两相 EOS。
- **性能**：单相 FCM 变量数减半（只 c，无 sg/so 两变量），Newton 更易收敛，预期比当前更快。
