> 本文件是 `src/programs/similarity.py` 与 `--field-port` 换算的数学依据，由
> `0918相似换算.md` 归并而来。函数级说明见该模块 docstring。

## 三维物理模型固定配置

| 固定参数 | 数值 |
|---|---|
| 模型长度 $L_m$ | 0.30 m |
| 模型宽度 $W_m$ | 0.30 m |
| 模型高度 $H_m$ | 0.30 m |
| 模型总体积 $V_m$ | 0.027 m³ |
| 实验温度 | 120 ℃ |
| 注入流体压力 | 50 MPa |
| 围压 | 60 MPa |
| 出口回压 | 50 MPa |
| 注入介质 | $\mathrm{CO_2}$ |
| 初始状态 | 样品饱和油 |
| 注入井 | 模型中心、中层 |
| 采出井 | 四周阶梯式分层布置，共 4 口 |

| 输入类别 | 输入参数 | 符号/单位 | 必要性及说明 |
|---|---|---|---|
| 矿场几何 | 矿场代表长度、宽度、厚度 | $L_p$、$W_p$、$H_p$；m | 必需，用于计算 $\lambda_x$、$\lambda_y$、$\lambda_z$ 和 $C_V$ |
| 流动路径 | 矿场代表注采距离 | $L_{c,p}$；m | 非等比例缩尺时必需 |
| 模型路径 | 模型代表注采距离 | $L_{c,m}$；m | 由最终井位尺寸图确定 |
| 时间 | 矿场或实验注入/采出/监测时间 | $t_p$：d；$t_m$：min | 与流量、累计体积任意给定两项 |
| 流量 | 矿场或实验体积注入流量 | $q_{V,p}$：m³/d；$q_{V,m}$：mL/min | 与时间、累计体积任意给定两项 |
| 累计量 | 矿场或实验累计注入体积 | $V_{inj,p}$：m³；$V_{inj,m}$：mL | 与时间、流量任意给定两项 |
| 体积基准 | CO₂ 体积计量状态 | 标准状态或实际温压状态 | 必需，输入与输出必须采用同一体积基准 |
| 井位换算 | 四口采收井精确坐标/完成层位置 | $x$、$y$、$z$；m 或 cm | 仅在需要输出等效井位时输入 |

## 通用函数

### 1. 三维几何相似比

$$
\lambda_x = \frac{L_p}{0.30},\qquad
\lambda_y = \frac{W_p}{0.30},\qquad
\lambda_z = \frac{H_p}{0.30}
$$

控制体积相似比：

$$
C_V = \lambda_x\lambda_y\lambda_z
= \frac{L_pW_pH_p}{0.027}
$$

### 2. 代表流动路径长度

$$
C_{L_c} = \frac{L_{c,p}}{L_{c,m}}
$$

矿场区域与模型等比例缩尺（$\lambda_x=\lambda_y=\lambda_z=\lambda$）时 $C_{L_c}=\lambda$。

### 3. 时间相似比

等线速度条件 $\dfrac{v_p}{v_m}=1$ 得：

$$
C_t = \frac{t_p}{t_m} = C_{L_c}
$$

### 4. 累计注入体积相似比

$$
C_{V_{inj}} = \frac{V_{inj,p}}{V_{inj,m}} = C_V
$$

### 5. 体积流量相似比

$$
C_{q_V} = \frac{C_V}{C_{L_c}}
$$

等比例缩尺时 $C_V=\lambda^3$、$C_{L_c}=\lambda$，化简为 $C_{q_V}=\lambda^2$。

## 矿场到实验室函数

$$
t_m(\mathrm{min}) = \frac{1440\,t_p(\mathrm{d})}{C_{L_c}}
$$

$$
q_{V,m}(\mathrm{mL/min}) = 694.444\,q_{V,p}(\mathrm{m^3/d})\frac{C_{L_c}}{C_V}
$$

$$
V_{inj,m}(\mathrm{mL}) = \frac{10^6V_{inj,p}(\mathrm{m^3})}{C_V}
$$

## 实验室到矿场函数

$$
t_p(\mathrm{d}) = \frac{C_{L_c}t_m(\mathrm{min})}{1440}
$$

$$
q_{V,p}(\mathrm{m^3/d}) = 0.00144\,q_{V,m}(\mathrm{mL/min})\frac{C_V}{C_{L_c}}
$$

$$
V_{inj,p}(\mathrm{m^3}) = \frac{C_VV_{inj,m}(\mathrm{mL})}{10^6}
$$

## 甲方实际需要输入的数据

| 输入 | 是否必需 | 说明 |
|---|---|---|
| 矿场长度 $L_p$ | 必需 | 计算 $\lambda_x$ |
| 矿场宽度 $W_p$ | 必需 | 计算 $\lambda_y$ |
| 矿场厚度 $H_p$ | 必需 | 计算 $\lambda_z$ |
| 代表流动距离 $L_{c,p}$ | 非等比例时必需 | 注入井到采出井代表距离 |
| 时间、流量、累计体积 | 任意两项 | 第三项由 $V=qt$ 得到 |
| CO₂ 体积计量状态 | 必需 | 标准状态或实际温压状态必须统一 |
| 四口采出井准确坐标 | 可选 | 只有需要换算井位时才输入 |
