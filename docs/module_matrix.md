# Module Matrix

Status values follow the project dashboard policy:

- `Backlog`: not started
- `Designing`: design exists but implementation is not complete
- `Coding`: code exists but functional scope or tests are incomplete
- `Testing`: tests exist but benchmark/validation is incomplete
- `Validated`: code, tests, and benchmark/validation report exist for MVP scope
- `Deliverable`: code, tests, docs, and validation report are complete enough for delivery

No module is marked `Deliverable` in this audit.
