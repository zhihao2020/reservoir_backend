# 组分前向模型实施与测试

> 依据 `docs/压力方程逐项对照.md`，把组分前向模型补齐到 OPM/MRST 的写法。
> 每条 = 具体改动 + 可运行的测试用例（断言）。测试落 `tests/test_compositional_fim.py`。
>
> **落地说明（对照代码，2026-09-29）**：步骤 4 实际采用**总烃摩尔平衡**，不是 MRST 偏摩尔体积加权。
> 步骤 5 的泡点失速被摩尔平衡顺带解决（无需变量切换）；自适应子步已有。
> 步骤 1 的 `accum·ct·(p−p0)` 写在溶液气/动力学压力步；双组分流体压缩性含在 `N(p)`。
> 步骤 6 的 30 天羽流测试已挂 `@pytest.mark.slow`。

## 总体顺序（按依赖）

```
步骤 1  压力方程加压缩性（B2）          ✅ 溶液气/动力学显式 ct；双组分含在 N(p)
步骤 2  压力方程加总重力通量（B3）      ✅ 气相 A_g / 动力学 grav 项
步骤 3  液相重力 + EOS 相密度（A 类）    ✅ gravity: eos 逐面 EOS 气头；井项改 EOS 摩尔体积
步骤 4  压力方程改摩尔平衡（B1）        ✅ 总摩尔平衡（非 ∂V/∂N_c 加权）
步骤 5  稳健性：泡点 + 自适应子步       ✅ 摩尔平衡消除失速；adaptive 已实现
步骤 6  全 GEM 场验证 + 质量守恒回归    进行中（slow 测试 + 方向性断言）
```

## 步骤 1：压力方程加压缩性（B2）

**状态**：✅ 溶液气 `_implicit_compositional_pressure_step` 与动力学
`_implicit_compositional_two_kinetic_step` 的 `r_p` / `J_pp` 含 `accum * params.ct * (p_ - p0)`。
双组分摩尔残差用 `accum*(N-N0)`，流体压缩性通过 EOS 的 `v_g(p), v_l(p)` 进入 `N`。

**改动**（体积形式，动力学/溶液气）：

```python
# residual()
r_p_ = A_ @ lam_t_ - q_vol_ + accum * params.ct * (p_ - p0)

# Newton loop
J_pp = (... + diags(D) + diags(accum * params.ct)).tocsr()
```

`accum = 1/(dt·inv_phiV) = φ·V/dt` 已存在；`p0` 是子步前压力（已在闭包内）。

**测试用例 T1.1 — 再循环被压低**：
- 输入：shale_oil，`k_diss=0`，跑 30 天。
- 断言：注入井 `sum(div_oil)/(qg·Bg) < 2.0`（修复前 5.90）。

**测试用例 T1.2 — 油相能饱和**：
- 断言：注入井 `Rs_act > 0.9·Rs_sat`（修复前 55.78/120.62 = 0.46）。

**测试用例 T1.3 — 自由气析出**（已实现为 `test_free_gas_forms_at_bubble_point`）：
- 断言：若干步后 `sg.max() > 1e-3`。

**测试用例 T1.4 — 压力储能守恒**：
- 单格封闭（无井），初压 p0，施加瞬时源后压力按 `φ·ct·Δp ≈ 源积分` 变化。

## 步骤 2：压力方程加总重力通量（B3）

**状态**：✅ 双组分压力与 CO₂ 方程的气相通量都走 `A_g = _phase_divergence_matrix(grid, k, p, rho_g)`
（按气相势 `p + rho_g·z` 迎风）；动力学步 `r_p = A@(λw+λl) + A_g@λg − q_vol + accum·ct·(p−p0)`。
复查修正：原写法 `A_g = A - params.rho_g * A_grav` / `- params.rho_g * (A_grav @ lam_g_)` 在 `rho_g > 0` 时
取了下游流度（`tests/test_gravity_upwind.py`）。`rho_g` 现可为标量或逐 z 面数组（`rock._face_geometry(z_head=…)`
把 z 面势差写成 `Δp + h_f·Δz`），逐面 EOS 头见步骤 3。

**原计划改动**（体积形式，下面代码是当时的草案，已被相势迎风写法取代）：

```python
# residual()
rho_g_ = _MW_gas / v_g_          # EOS 气相密度 (kg/m3)
rho_l_ = _MW_OIL / 1000.0 / v_l_  # EOS 液相密度
grav = g * A_grav @ (lam_g_ * rho_g_ + lam_l_ * rho_l_)
r_p_ = A_ @ lam_t_ - q_vol_ + accum * params.ct * (p_ - p0) - grav
```

**测试用例 T2.1 — 总质量守恒（含重力）**：
- 断言：稳态时 `Σ_cells (A@λt − grav − q_vol) ≈ 0`（总散度 = 总源）。

**测试用例 T2.2 — 无重力退化**：
- 设 `rho_g = rho_l = 0`，结果退化为步骤 1（对照回归）。

## 步骤 3：液相重力 + EOS 相密度（替代固定 rho_g）

**状态**：✅ 已落地。`black_oil.gravity` 默认 `scalar`（固定 `rho_g`，回归可复现）；`eos` 时
双组分 / 三组分 / 全组分摩尔步用逐 z 面 EOS 气头 `g·(ρ_g − ρ_l)`（`_eos_gas_head`，饱和度加权面密度）。
相密度 `ρ = (x·MW)/v` 来自 `pr_eos.phase_mass_densities`（Peneloux 后的 `v_l, v_g`）。
液相仍以 `p` 为参考势（避免重初始化静水平衡）；无气相的面回退到标量 `rho_g`。
井项（two/three/full）不再用标量 `Bg`：生产井 `qg_mol = WI·λg·Δp/v_g`、`qo_mol = WI·λl·Δp/v_l`，
注入井 `WI·λt·Δp/v_CO2(p)`，定注速目标仍是 `qg_target/_V_CO2_STD` 摩尔数。地面油体积继续用
`_MW_OIL_DEAD/_RHO_OIL_STD`（800 kg/m³），不换成 PR 标准态密度。`_MW_OIL` 已删除，`rs_sat` 改死油基。

```python
rho_l, rho_g = phase_mass_densities(x, y, v_l, v_g)  # kg/m3
head = _eos_gas_head(grid, sl, sg, rho_l, rho_g, fallback=params.rho_g)
A_g = _phase_divergence_matrix(grid, k, p, head)     # 相势迎风
```

**测试用例 T3.1 — 浮力方向**（`test_eos_co2_denser_than_oil`）：
- 20 MPa 纯 CO₂ 密度 > 死油密度（下沉）。

**测试用例 T3.2 — 密度对压强敏感**（`test_eos_gas_density_rises_with_pressure`）：
- `ρ_g(22 MPa) > ρ_g(20 MPa) > ρ_g(15 MPa)`，且 20 MPa 纯 CO₂ ≈ NIST 590 kg/m³。

**测试用例 T3.3 — 常密度退化为标量**（`test_eos_gas_head_reduces_to_scalar_when_densities_constant`）：
- 钉死 `ρ_g, ρ_l` 时逐面头 = `g·(ρ_g−ρ_l)`，算子与标量 `rho_g` 一致。

**测试用例 T3.4 — 井摩尔一致**（`test_injector_moles_match_surface_target` / `test_producer_gas_moles_use_eos_molar_volume`）：
- 定注速：累积摩尔 = `qg_target·dt/_V_CO2_STD`；生产井摩尔走 EOS `v_g, v_l`，不是 `Bg`。

**30 天底部羽流**（`test_bottom_plume_sinks`，默认 `gravity: scalar`）：方向性断言底部 `sg` > 顶部。

GEM 真值（`shale_oil/cmg_fields.csv`，t = 30 d）：底部 k0–2（z≤0.05）`sg` = **0.456**，顶部（z≥0.27）= **0.081**，`n(sg>0.1)` = 527，注入井目标 `sg → 0`。

对照（`.tmp_plume30.py`，第 3 天，scalar 与 eos 都 `conv=True`，约 12 min/天，30 天尚未跑完）：

| | 底部 sg | 顶部 sg | n(sg>0.1) | 注入井 sg | p (MPa) |
|---|---|---|---|---|---|
| GEM 30 d | 0.456 | 0.081 | 527 | 0 | — |
| scalar 第 3 天 | 0.000 | 0.000 | 0 | 0.059 | 19.00 |
| eos 第 3 天 | 0.000 | 0.000 | 0 | 0.056 | 19.00 |

底部远低于 0.456，自由气还停在注入井。短时 20 步（约 4.8 h）scalar/eos `mean|Δsg|≈1e-7`，同样没有底部羽流。

## 步骤 4：压力方程改总摩尔平衡（B1）

**状态**：✅ 已落地。实际实现**不是**偏摩尔体积加权 `peq = Σ(∂V/∂N_c)·R_c`，而是总烃摩尔平衡：

```
r_p = accum·(N − N0) − q_N + A_g@(λg/v_g) + A@(λl/v_l)
q_N = qg_mol + qo_mol   # 生产井 λ/v；注入井 λt/v_CO2(p)
```

油组分 = 总摩尔 − CO₂，随两条守恒自动守住。`v_g = v_l` 时回到体积平衡。

**测试用例 T4.1 — 油组分守恒**（已实现为 `test_molar_pressure_conserves_oil`）：
- 断言：三步注入后 `|Δ oil_moles|/oil0 < 1e-2`。
