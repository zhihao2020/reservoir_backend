# 组分前向模型实施与测试

> 依据 `docs/压力方程逐项对照.md`，把组分前向模型补齐到 OPM/MRST 的写法。
> 每条 = 具体改动 + 可运行的测试用例（断言）。测试落 `tests/test_compositional_fim.py`。

## 总体顺序（按依赖）

```
步骤 1  压力方程加压缩性（B2）          ← 再循环诊断指向，最高优先级
步骤 2  压力方程加总重力通量（B3）
步骤 3  液相重力 + EOS 相密度（A 类）    ← 替代固定 rho_g 标量
步骤 4  压力方程改摩尔加权（B1, MRST 式） ← 油组分守恒
步骤 5  稳健性：泡点变量切换 + 自适应子步
步骤 6  全 GEM 场验证 + 质量守恒回归
```

---

## 步骤 1：压力方程加压缩性（B2）

**改动**：在 `_implicit_compositional_two_step`（及其三/全/动力学步）的残差与 Jacobian：

```python
# residual()
r_p_ = A_ @ lam_t_ - q_vol_ + accum * params.ct * (p_ - p0)

# Newton loop
J_pp = (... + diags(D) + diags(accum * params.ct)).tocsr()
```

`accum = 1/(dt·inv_phiV) = φ·V/dt` 已存在；`p0` 是子步前压力（已在闭包内）。

**测试用例 T1.1 — 再循环被压低**：
- 输入：shale_oil，`k_diss=0`，跑 30 天。
- 断言：注入井 `sum(div_oil)/(qg·Bg) < 2.0`（修复前 5.90）。

**测试用例 T1.2 — 油相能饱和**：
- 断言：注入井 `Rs_act > 0.9·Rs_sat`（修复前 55.78/120.62 = 0.46）。

**测试用例 T1.3 — 自由气析出**：
- 断言：`(sg > 0.01).sum() > 0`（修复前 0）。

**测试用例 T1.4 — 压力储能守恒**：
- 单格封闭（无井），初压 p0，施加瞬时源后压力按 `φ·ct·Δp ≈ 源积分` 变化。

---

## 步骤 2：压力方程加总重力通量（B3）

**改动**：`r_p` 加总重力通量（气相 + 液相，EOS 密度）：

```python
# residual()
rho_g_ = _MW_gas / v_g_          # EOS 气相密度 (kg/m3)
rho_l_ = _MW_OIL / 1000.0 / v_l_  # EOS 液相密度
grav = g * A_grav @ (lam_g_ * rho_g_ + lam_l_ * rho_l_)
r_p_ = A_ @ lam_t_ - q_vol_ + accum * params.ct * (p_ - p0) - grav
```

**测试用例 T2.1 — 总质量守恒（含重力）**：
- 断言：稳态时 `Σ_cells (A@λt − grav − q_vol) ≈ 0`（总散度 = 总源）。

**测试用例 T2.2 — 无重力退化**：
- 设 `rho_g = rho_l = 0`，结果退化为步骤 1（对照回归）。

---

## 步骤 3：液相重力 + EOS 相密度（替代固定 rho_g）

**改动**：把 `A_g = A − params.rho_g·A_grav` 的固定标量 `rho_g` 换成 EOS 相密度差：

```python
# 气相浮力头 = (rho_CO2 − rho_oil)·g，从 phase_molar_volumes 导出
rho_CO2_ = _MW_CO2 / v_g_
rho_oil_ = _MW_OIL / 1000.0 / v_l_
head_g_ = (rho_CO2_ - rho_oil_) * g     # per-cell 数组，替代标量
A_g_ = A_ - head_g_ * A_grav
```

液相 CO₂ 通量也走 `A_g`（CO₂ 富油相更重、下沉）。

**测试用例 T3.1 — 浮力方向**：
- 单相纯 CO₂（z→1）时 `head_g > 0`（下沉）；纯油（z=0）时 `head_g ≈ 0`。

**测试用例 T3.2 — 密度对压强敏感**：
- `head_g(20 MPa) > 0` 且 `head_g(15 MPa)` 与 20 MPa 不同（不再是标量）。

---

## 步骤 4：压力方程改摩尔加权（B1，MRST 式）

**改动**：压力方程从「总流度体积平衡」改为「偏摩尔体积加权的组分残差和」：

```
peq = Σ_c (∂V/∂N_c) · R_c
```

实现上用数值偏导近似偏摩尔体积（或用 `phase_molar_volumes` 对 z 求导）。

**测试用例 T4.1 — 油组分守恒**：
- 断言：`Σ φV·ΔN_oil ≈ Σ q_oil·dt`（修复前油摩尔泄漏，B1）。

**测试用例 T4.2 — 与体积平衡在极限一致**：
- 单组分（无 CO₂，纯油）时，摩尔加权压力方程退化为体积平衡（回归）。

---

## 步骤 5：稳健性（泡点变量切换 + 自适应子步）

**改动**：泡点穿越时用变量切换（单相区用 z，两相区用 sg/x），或更保守的 dt 回退 + 重试。

**测试用例 T5.1 — 泡点穿越收敛**：
- 单步 dt 跨泡点（z 从 0.3→0.5），断言 `conv=True`（修复前失速）。

**测试用例 T5.2 — 30 天无 warning**：
- 断言 30 天跑完无 `did not converge` warning。

---

## 步骤 6：全 GEM 场验证 + 质量守恒回归

**测试用例 T6.1 — 底部羽流**：
- 30 天，断言 `bottom k0-2 sg 均值 ∈ [0.3, 0.6]`（真值 0.456）。

**测试用例 T6.2 — 注入井 sg ≈ 0**：
- 断言注入井 `sg.mean() < 0.05`（真值 0）。

**测试用例 T6.3 — 质量守恒**：
- 断言 `ΣφV·Δ(sg/Bg + Rs·sl) ≈ Σ(q_g + Rs·q_l)·dt`（净注入 = 累积）。

**测试用例 T6.4 — 压降/注速自洽**：
- 断言注入井地面气速率 ≈ 8.33e-8 m³/s（定流量约束）。
