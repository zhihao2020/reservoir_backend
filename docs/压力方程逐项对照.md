# 组分压力方程逐项对照（OPM / MRST / 本项目）

> 目标：把本项目的组分前向模型压力方程，逐项对照 OPM Flow 与 MRST `ad-compositional` 的标准写法，
> 找出缺失项并给出修复。源码依据：`reference_projects/MRST-main/autodiff/compositional/utils/equationsCompositional.m`
> 与 `reference_projects/opm-simulators-master`。

## 一、三者的方程骨架

### 1. 组分摩尔守恒（共同基础）

组分 c 的**摩尔**守恒（c = 1..ncomp）：

```
∂(φ Σ_α ρ_α S_α X_cα)/∂t + ∇·(Σ_α ρ_α X_cα v_α) = Σ_α ρ_α X_cα q_α      (1)
```

- `ρ_α`：相 α 的**摩尔密度**（mol/m³），由 EOS 给（`ρ_α = P/(Z_α R T)`）。
- `X_cα`：组分 c 在相 α 的摩尔分数（`x_c` 液相 / `y_c` 气相）。
- `v_α`：相 Darcy 速度（含重力）。

**MRST 实际实现**（`equationsCompositional.m`）：

```matlab
eqs{i} = (pv/dt).*( rhoO.*sO.*xM{i} - rhoO0.*sO0.*xM0{i} + rhoG.*sG.*yM{i} - rhoG0.*sG0.*yM0{i} );
fluxes{i} = rOvO.*upstr(xM{i}) + rGvG.*upstr(yM{i});
```

即**摩尔**累积 + **摩尔**通量（`rhoO·vO`、`rhoG·vG`），密度与摩尔分数都来自 EOS 闪蒸。

**OPM**：同式 (1)，摩尔形式。

**本项目**：用**表面体积**守恒 `C = z·N·V_CO2_STD`，通量 `y·λg/v_g + x·λl/v_l`。
数学上等价于摩尔形式（`V_STD/v_α` 是换算因子），但密度来源不同（见 §二）。

### 2. 相 Darcy 速度（含重力）

```
v_α = -k (kr_α/μ_α) (∇p_α − ρ_α g ∇z)                                    (2)
```

- **MRST**：`dpO = Grad(p) − rhoOf·gdz`，`vO = −upstr(mobO)·T·dpO`。**每一相**都带自己的
  密度重力头 `ρ_α·g·∇z`。
- **OPM**：同 (2)，每相密度重力。
- **本项目**：只有**气相**带重力 `A_g = A − rho_g·A_grav`，`rho_g` 是**固定标量**；
  液相无重力（`A @ (x·λl/v_l)` 用 `A` 不是 `A_g`）。

### 3. 压力方程（核心差异）

**MRST**：压力方程是**摩尔平衡的体积加权和**——

```
peq = Σ_c (∂V/∂N_c) · R_c = 0                                            (3)
```

其中 `∂V/∂N_c` 是组分 c 的**偏摩尔体积**（`getPartialVolumes` 对相体积关于组分求导得到），
`R_c` 是组分 c 的摩尔残差。物理含义：`Σ (∂V/∂N_c) dN_c = dV`，即**总体积守恒**。
它天然**包含压缩性**（`R_c` 里的累积项）与**重力**（`R_c` 里的通量项），不是单独另写的椭圆方程。

**OPM**：压力方程同样是**体积平衡**（或总质量平衡），含**总压缩性** `c_t = c_r + Σ S_α c_α`
与**重力总通量**。

**本项目**：

```
r_p = A@λt − q_vol = 0        （纯椭圆 / 稳态体积平衡）                   (4)
```

三条缺失：
1. **无压缩性**：没有 `∂φ/∂t = φ c_t ∂p/∂t`。
2. **无重力**：`A@λt` 只有压力梯度项，没有 `Σ λ_α ρ_α g ∇z`。
3. **无摩尔加权**：用总流度 `λt`，不是偏摩尔体积加权。

## 二、逐项对照表

| 项 | OPM Flow | MRST ad-compositional | 本项目 | 结论 |
|---|---|---|---|---|
| 组分守恒形式 | 摩尔 `ρ X v` | 摩尔 `rhoO·sO·xM` | 表面体积 `z·N·V_STD` | ⚠️ 等价但密度源不同 |
| 相摩尔密度 ρ_α | EOS `P/(ZRT)` | EOS `rhoO/rhoG`（闪蒸给） | 表面 `V_STD` + 固定 `Bg` | ✅ 已部分 EOS 化（Peneloux） |
| 重力 | 每相 `ρ_α g` | 每相 `rhoOf·gdz` | 仅气相、固定 `rho_g` 标量 | ❌ 缺液相 + 固定标量 |
| 压力方程类型 | 抛物线（含 ∂φ/∂t） | 体积加权摩尔和（含累积） | 纯椭圆（稳态） | ❌ 缺 ∂φ/∂t |
| 压缩性 | `c_t = c_r + Σ S c_α` | 隐含在偏摩尔体积 | 无 | ❌ 缺 |
| 压力方程来源 | 体积平衡 | `Σ(∂V/∂N_c)·R_c` | 总流度 `λt` | ⚠️ 需改 |
| 井模型 | Peaceman + 完整井 Jacobian | 同样 | Peaceman + 定流量 Schur | ✅ 已对齐 |

## 三、修复方案（按优先级）

### 修复 1（关键，诊断已指向）：压力方程加压缩性

```
r_p = A@λt − q_vol + accum·ct·(p − p0)          accum = φ·V/dt
J_pp += diags(accum·ct)
```

`ct = params.ct`（已有，1.2e-9）。这压掉过量再循环（诊断的 5.9×），让油相能饱和。

### 修复 2：压力方程加重力总通量

```
r_p = A@λt − q_vol − g·A_grav @ (λg·ρg + λl·ρl)    （ρ 用 EOS 相密度）
```

使总质量守恒，且气相/液相浮力都进总平衡。

### 修复 3（长期，MRST 式）：压力方程改摩尔加权

用偏摩尔体积加权组分残差 `peq = Σ(∂V/∂N_c)·R_c`，一步到位对齐 MRST，同时解决
「体积平衡 ≠ 摩尔平衡（v_g ≠ v_l）导致油组分泄漏」的审计 B1。

### 修复 4：液相重力 + EOS 密度

液相也带 `ρ_l g ∇z`（CO₂ 富油相更重、下沉），密度从 `phase_molar_volumes` 导出，
替代固定 `rho_g` 标量。

## 四、与现有代码的对应

- `accum = 1/(dt·inv_phiV)` 已在所有组分步里；缺的只是把 `accum·ct·(p−p0)` 加进 `r_p` 与 `J_pp`。
- `A_grav = _gravity_divergence_matrix(...)` 已有，缺的是把总重力通量加进 `r_p`。
- `phase_molar_volumes` / `flash_direct_volumes` 本轮已加，可供重力与摩尔加权用密度。
